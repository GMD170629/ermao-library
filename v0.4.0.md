# v0.4.0

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本强化完整导入流程，加入原子化上传发布、多来源书籍身份识别，以及监控目录消失或文件仍在变化时更安全的恢复机制。

书库体验新增更清晰的批量操作权限、持久化排序偏好和更整洁的功能分层上传流程，并完整支持中英文。

数据库基线、文本和媒体导入校验也得到整合，同时扩展后端、Web、PWA、授权、迁移和工作进程回归测试。

## English

Shuku Starship v0.4.0 strengthens the complete import workflow with atomic upload publication, multi-source identity resolution, and safer recovery when monitored folders disappear or files are still changing.

The library experience now includes clearer batch-action authorization, persistent sorting preferences, and a cleaner feature-layer upload flow with complete zh-CN and en-US copy.

This release also consolidates the current database baseline, improves text and media import validation, and expands backend, Web, PWA, authorization, migration, and worker regression coverage.
