# v0.5.1

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本集中升级阅读体验：重构阅读器控制面板和移动端布局，新增更完整的 EPUB、漫画与 PDF 排版、页宽、翻页和显示偏好，并改进漫画连续阅读、翻页缓存、唤醒锁及阅读进度恢复。为避免重复入口，“设置”中的“当前设备偏好”页面已移除，相关偏好统一在阅读时调整；PDF 连续滚动暂时关闭，以保证当前版本的阅读稳定性。

书库管理新增作品合并流程、移动端批量操作和更可靠的卷册封面处理。元数据 OPF 回写、队列恢复、文件变更观察和导入兼容性得到加强，同时补充阅读进度、书库查询与系统事件索引迁移，改善大型书库下的查询性能和故障恢复。

## English

This release substantially upgrades reading: reader controls and mobile layouts are redesigned, EPUB, comic, and PDF typography and display preferences are expanded, and comic continuous reading, page caching, wake lock, and progress restoration are improved. The redundant “This Device” settings page is removed so reading preferences are managed directly while reading. PDF continuous scrolling is temporarily disabled to preserve stability in this release.

Library management now includes work merging, improved mobile batch actions, and more reliable volume-cover handling. OPF metadata writeback, queue recovery, file-change observation, and import compatibility are strengthened, while new progress, library-query, and system-event indexes improve performance and recovery for larger libraries.
