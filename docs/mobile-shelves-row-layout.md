# Mobile 书架：行式目录 v2

状态：用户确认，2026-08-27。限书架浏览能力；不改变 Web、后端、Book/Resource 身份和 Reader 契约。

本决定覆盖 Phase 1–5 中与“书架根页不提供搜索”、旧的封面在左构图冲突的规定，其他功能、授权、Warm Page 和平台原生规则继续有效。

## 已确认构图

- [书架根页](assets/mobile-shelves-v2/root-approved.png)：原生标题、创建动作、搜索、`全部 / 书架 / 合集`、连续行式列表、书架 Tab。
- [合集二级页](assets/mobile-shelves-v2/collection-approved.png)：原生返回/标题/菜单、数量、合集内搜索、成员书架列表；不直接展示合集里的图书列表。
- 每行左侧名称与数量，右侧最多三张完整 2:3 封面和系统 chevron。行之间为细分隔线，不增加卡片或封面裁切。
- 大字号减少预览封面数量，保留可读文字和至少 44pt/48dp 的操作目标。系统导航栏、状态栏、Tab 样式由 iOS/Android 提供，不复制图稿中的设备装饰。
- 动态名称和封面来自服务器；图稿中的名称、数量只用于设计校准，不写入真实账号。

## 页面与数据

```text
书架 Tab → 合集 → 成员书架 → 图书既有内容入口
         → 普通/智能书架 → 图书既有内容入口
```

- 根页使用 `GET /api/shelves` 完整授权摘要。全部显示所有书架和合集；书架显示 STATIC/SMART（包含已加入合集的书架）；合集只显示 COLLECTION。保留服务端顺序。
- 搜索按当前 scope 匹配名称/描述，不搜索图书，不只过滤已加载的一页。每个 scope 保留自己的搜索词。
- 合集成员按摘要的 `collectionIds` 从完整目录投影；合集二级身份通过既有详情接口重新验证。合集三封面取成员书架的预览图书，按 bookId 去重；不为每张封面增加详情请求。
- 普通/智能书架详情通过既有 `GET /api/shelves/{id}?page=N&pageSize=24&includeBookIds=false` 顺序分页。点击图书推进来源 Tab 中的既有 Book 路由，不自动启动 Reader。
- 智能书架只读；展示描述或自动规则提示，未知规则提示回到 Web 查看，不编辑或转成普通书架。
- 新建 Sheet 支持普通书架、合集及合集成员选择，经 `POST /api/shelves` 确认成功后刷新并进入新对象。没有自动创建、自动测试写入真实服务器或乐观假成功。
- 本轮不扩展智能规则编辑、批量整理、合集编辑/删除或离线目录缓存；这些不是本次确认的展示流程。

## 状态与授权

- Loading / empty / no matches / network error / inaccessible 都保留导航壳；错误行提供重试，不弹全局错误对话框。
- 首次或显式刷新失败清除旧 GET 内容；下一页失败保留当前 generation 已加载页，并重试同一页。授权失败清除私有内容并交给现有重新登录入口。
- 请求取消或 generation 不匹配时拒绝发布旧响应。封面沿用认证请求和 server/user/authz namespace，不把用户封面变为公开链接。
- `zh-CN` / `en-US` 的标签、表单、错误、空态和辅助功能文案齐全；计数按当前 locale 格式化。
