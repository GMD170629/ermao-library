# 二毛图书品牌与应用图标

## 名称

正式产品名：**二毛图书**。

名称直接来自作为品牌主角的白猫“二毛”，比通用书库名称更有个人记忆点，也更符合私人部署、长期陪伴式阅读产品的气质。

仓库名、包名、Docker 镜像、应用路径、备份标识及存储键继续使用 `shuku-starship`，避免破坏既有安装与历史数据兼容性。

## 图标方向

图标以用户提供的二毛照片为原型，保留白色长毛、额头灰斑、浅黄绿色眼睛、粉色鼻子与平静略严肃的神态。成品采用圆形徽章构图与适度抽象的编辑插画风，去除人物和照片背景，在小尺寸下仍以白猫轮廓与眼睛形成识别。

- 徽章色：珊瑚橙 `#E96545`
- 底色：暖象牙白 `#F7F1E8`
- 辅助色：暖灰、炭黑、浅黄绿色、淡粉色
- 风格：圆形单一主体、适度抽象、无文字，兼容 16px favicon、PWA 图标与 fnOS 桌面图标

## 资产

- 原始生成图：`apps/web/public/brand/ermao-library-app-icon-v1.png`（1024×1024）
- Web / PWA：`apps/web/public/icons/`、根目录 favicon 与 Apple Touch Icon
- fnOS：`deploy/fnos/ICON.PNG`、`ICON_256.PNG` 及 `app/ui/images/`

## 生成记录

- 模式：ImageGen，基于用户提供照片进行图像转化
- 参考重点：仅提取白猫主体；保留长毛、额头灰斑、浅黄绿色眼睛、粉色鼻子与原有神态；排除人物、眼镜、房间和照片背景
- 视觉约束：圆形珊瑚橙徽章、暖象牙白背景、正面猫头像、编辑插画式适度抽象、无文字与额外图形
- 衍生方式：从生成母版等比缩放为 PWA、favicon、Apple Touch Icon 与 fnOS 所需尺寸，不改变核心构图
