# 空间管理

[页签导航示意](../design/storage-management/desktop-tab-v1.png)。页签内容采用迁移前的实际界面。

- 将「空间管理」纳入「数据和系统」页签。页签依次为「备份与恢复」「空间管理」「网络与代理」，默认打开「备份与恢复」。侧边栏由「数据和系统」统一进入。
- 复用「智能整理」的 `SettingsTabs` 样式，选中项使用橙色文字和细下划线。空间统计、刷新和清理在页签内容区，使用既有 Shell、Button 和视觉 token。
- 只遍历 STORAGE_ROOT 文件属性一次，返回九类字节汇总；不读取内容、查询书籍引用或遍历挂载书库。
- 清理统一直接删除 cache、logs、backups、update-tmp/prepared、automation-uploads 目录，不查询业务记录或维护特殊状态；保留更新控制目录。
- 进入和手动刷新统计；清理后仅重新统计对应分类。无后台任务、持久化统计或批量清理。
- 定向验证分类、文件边界、清理与状态保护，以及 Web 类型、双语和交互。
