# 手机端有声书播放器 Phase 0/1 设计与工程基线

状态：Phase 0/1 工程实现完成，真机验收待执行。本文冻结移动端实现所需的状态、交互与验收语义；现有
`docs/assets/mobile-app-hifi-v1/audio-now-playing-v1.png` 仍是视觉事实来源。
本文不建立新的服务端协议，也不替代 Reader Safety 机器合同。

## 1. 全局会话与导航

- 唯一全屏目的地为 `audio.now-playing(resourceId, assetId?, location?)`。
- 从作品详情、首页或 Download Center 明确点击“开始/继续收听”时进入全屏并播放。
- 冷启动、进程恢复、重新认证和系统中断恢复只恢复暂停态，绝不自动出声。
- 四个 Tab 共享一个 App 根音频会话。收起、系统返回、切 Tab 不释放引擎。
- Reader 打开时音频继续，mini player 隐藏；回到 Shell 后恢复显示。
- 切换作品资源采用两阶段提交：新 bootstrap 和新 engine source 都成功后才替换旧会话。

## 2. Now Playing 冻结层级

从上到下保持以下层级，不增加波形、旋转封面、装饰渐变或持续动画：

1. 收起、页面标题、更多菜单；
2. 封面；
3. 作品名、资源/音轨名、当前章节；
4. 可拖动时间轴、已播放时间、剩余/总时长；
5. 上一章节、后退 15 秒、播放/暂停、前进 30 秒、下一章节；
6. 倍速、章节、睡眠定时、查看作品。

更多菜单中的“停止播放”必须先保存进度，再清理 engine、全局会话和 mini player，
不显示确认框。系统 Stop 只等价于暂停并保存。

## 3. Compact 状态矩阵

| 状态 | 全屏主区 | mini player | 用户动作 |
|---|---|---|---|
| loading | 封面占位与加载提示；主控制暂不可用 | 不显示首个未提交会话 | 可返回；旧会话继续 |
| playing | 主按钮为暂停，时间轴递增 | 暂停、展开 | 暂停、seek、章节、倍速 |
| paused/ready | 主按钮为播放，时间轴保持 | 播放、展开 | 播放、seek、停止 |
| buffering | 时间轴与控制保留，主按钮显示缓冲语义 | 缓冲、展开 | 可暂停；不可重复 load |
| retryable error | 行内错误和“重试” | 错误、展开 | 重试；有精确本地工件时可回退 |
| codec unsupported | 稳定错误码对应文案 | 错误、展开 | 返回或切换资源，不尝试转码 |
| reauthenticate | 已暂停并保存；显示重新认证入口 | 暂停态，不自动继续 | 认证成功后手动播放 |
| sync pending | 播放不阻断；显示轻量同步状态 | 不占用主要控制 | 等待 outbox 或主动重试 |
| ended | 位置固定在结尾，主按钮可重播 | 播放、展开 | 重播或下一资源 |

mini player 固定在 Tab 栏上方，包含封面、标题/章节、轻量进度、播放/暂停和展开。
它不提供关闭按钮；停止播放只在全屏更多菜单中出现。

## 4. Sheet 与 Menu

- 章节/音轨使用 Sheet。选中章节后 Sheet 保持展开，并更新选中态与当前时间。
- 倍速使用 Menu，顺序固定为 `0.75、1、1.25、1.5、1.75、2、2.5、3`。
- 睡眠定时使用 Sheet：关闭、15/30/45/60 分钟、本章结束、当前音轨结束。
- 无章节时“本章结束”等价于“当前音轨结束”。定时器是会话态，进程死亡后不恢复。

## 5. 本地工件与失败恢复

本地播放必须同时匹配：

`serverIdentity + userId + authzVersion + bookId + resourceId + assetId`

并验证 completed 状态和原始字节长度。身份不匹配、缺失或损坏时停留在暂停/重试；
不自动重下载，不把本地失败伪装成在线播放成功。安全拒绝、DRM、codec 不支持不得回退到
其他解析器、整文件在线正文或转码。

## 6. 双语与可访问性

- 所有非用户内容同时提供 `zh-CN` 和 `en-US`；书名、作者、章节等用户内容保持原文。
- VoiceOver/TalkBack 顺序：页面标题 → 作品身份 → 章节 → 时间轴 → 主控制 → 次级操作。
- 播放按钮的可访问名称随状态变化；缓冲状态必须单独播报，不能反复抢焦点。
- seek 控件暴露当前时间、总时长和可调整动作；上一/下一章节在边界处报告不可用。
- iOS 触控目标至少 44pt，Android 至少 48dp。最大字体时允许控制换行，不截断主动作。
- Reduced Motion 下不做封面、进度或 Sheet 的装饰性连续动画。

## 7. 截图与真机证据

每个平台保存设备、系统版本、构建号和语言，至少覆盖：默认 A07、mini player、章节
Sheet、睡眠 Sheet、buffering、可重试错误、codec 不支持、重新认证、Light/Dark、最大字体、
锁屏/通知。Phase 0 的证据不应宣称后台连续播放；Phase 1 必须使用实体 Android 和实体 iPhone。
