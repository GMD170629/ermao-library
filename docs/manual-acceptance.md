# 手工验收清单

## 通用流程

1. 未登录访问 `/library` 会跳转到登录页，登录后可进入系统。
2. 在 `/settings` 将 `/books` 添加为书库根目录并选择 `VOLUMES`，放入 `/books/三体/中文版/01.epub` 后扫描；数据库与详情页必须显示 Work“三体”、Version“中文版”和 Volume“01”。
3. 在 `FLAT` 与 `AUDIOBOOK` 根目录分别检查根文件、多音轨单卷和多卷目录，`/import-tasks` 能查看扫描器创建的任务与结果。
4. 在 `/library` 上传文件时，目标必须位于已启用书库根目录且符合组织方式；上传不能通过标题或表单字段另行创建、合并或转移 Work / Version / Volume。
5. 页面不再暴露重复作品合并、作品拆分、媒体版本转移或派生格式入口。
6. 在 375px 宽度下检查登录、书库、详情、导入任务、设置和阅读器无横向溢出。

## Reader v4 下载后阅读真机发布门槛

Web 项目必须分别在真实 iPhone Safari 与主屏幕安装的 PWA 中完成；Android／iOS 原生项目必须使用明确选择的物理设备。模拟器与 Playwright 结果不能替代。未填写设备、系统与验收人前，Reader v4 不视为达到发布门槛。

- [ ] 记录 iPhone 型号、iOS 版本、Safari 版本、PWA 安装时间、验收人和日期。
- [ ] Safari 与主屏幕 PWA 显示同一套 Web 导航和页面，不跳转到 `/mobile` 或启用专用触控界面。
- [ ] EPUB、FB2、TXT、MOBI、AZW、AZW3、PRC 首次点击阅读均进入加载页；响应仍未结束时真实字节和百分比已递增，Reader 尚未打开。
- [ ] 下载完成后正文来自已缓存原文件；阻断 reflowable manifest、positions 和章节端点仍可阅读、目录跳转和精确恢复。
- [ ] 取消 Web 加载会中止请求并删除未完成缓存；再次阅读从零下载。完整缓存重开不重复请求正文，删除缓存或更新资产版本后重新下载。
- [ ] Android／iOS 的同一动作创建或复用 Download Center 卷册任务；暂停、恢复、文件缺失重建、配置／进程恢复和账号切换不会重复任务或迟到打开。
- [ ] 下载后原始格式、长度和 SHA-256 与媒体端点一致，不存在派生 EPUB、ZIP 或持久化解包目录。
- [ ] EPUB 分页为单页居中，宽屏不出现双页；顶部与底部均有可见留白。
- [ ] EPUB 分页/滚动模式、三种字体、五种主题可即时切换；重开后保持，重置后恢复阅读器默认。
- [ ] EPUB 方向键、PageUp/Down、Space/Shift+Space、Home/End、点击区、中心控件与横向滑动一致；文本选择和内部/外部链接优先级正确。
- [ ] 漫画单/双页、左右方向、奇偶页、适配、缩放、卷切换与快速翻页正常，切换后图片请求和缓存不持续增长。
- [ ] PDF 页码、适宽/适页、缩放、文本选择、密码输入、损坏文件与重试/返回书库流程正常；连续操作无白屏或崩溃。
- [ ] 漫画和有声书入口不创建隐式完整下载；Web PDF 继续在线 Range。原生 PDF 仅在 PDFium 请求超出易失缓存时静默创建／复用 Download Center 任务，完成后原会话切源，关闭 Reader 不删除任务。
- [ ] 断网显示明确错误，恢复网络后进度按顺序补交；两个标签页同时阅读时只有一个 Outbox 发送者。
- [ ] 阅读中发现 Service Worker 更新时仅提示，不自动刷新；安全时点确认后才升级。
- [ ] EPUB、漫画、PDF 各连续翻页 50 次并往返书库，iframe、Object URL、Canvas、render task 与事件监听器不持续增长。
