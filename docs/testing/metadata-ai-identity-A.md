# 任务 A：标题作者识别

基于任务 R 的 `fcd53e1e78f36fdaf81b1d10aa923fcb1ee2a370` 开发，没有合并旧增强分支。

复用现有 AI Source 配置、Chat Completions 连接、来源适配器、识别弹窗及元数据应用接口。identity 只返回 title、author、needsReview、reason。只发送当前目标标题作者、至多 8 个资产的已导入内嵌标题作者、文件名及有限目录名，不读取或上传正文。

同一 identity 结果进入来源查询和共享候选选择；删除取第一条候选的旧选择分支和旧 AI 多字段建议路径。AI 身份结果也可直接勾选保存。自动应用可纠正未保护的标题作者，其他字段仍遵循本地优先；不确定结果留给用户在原弹窗核对。关闭 AI 时不调用模型；配置测试实际调用配置的模型，支持不需要 API Key 的模型。
