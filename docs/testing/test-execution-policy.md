# 最小充分验证与测试执行策略

本文是测试选择、扩大条件、结果复用及执行入口的唯一详细来源。[根规则](../../AGENTS.md) 定义最小修复和停止条件，[工程实现规范](../engineering-standards.md) 与专项契约定义应保护的行为。控制无必要执行成本，不降低测试真实性。

## 默认验证

确认原失败、直接原因、预期和实际调用范围后，复用已有测试与工具，选择：

- 能直接证明原失败已修复的针对性测试；
- 实际受影响的关键相邻行为和必要反例；
- 对应模块必要的编译、类型或静态检查。

字段映射、条件判断、页码转换、按钮状态、已明确的缓存覆盖规则等小修复，默认按此执行。不能仅凭代码量小判定低风险，也不能因术语或共享文件名自动扩大范围。

测试层级对应真实故障：界面错误不能只凭底层单测宣布界面通过，需要时复测原界面路径；已隔离的显示问题不必重演整套导入、断网、跨端、强杀或长时间播放。现有夹具/准备状态仍代表真实契约时可复用；需要的集成或真机证据不能用不相关底层测试替代。

## 入口、批量验证与结果复用

- 执行前查看既有脚本、过滤参数、前置构建与其他耗时前置步骤，优先使用现有定向入口。已有测试足够时直接复用；缺少原失败覆盖时只补必要测试。
- 无可靠局部命令时执行最小可用模块检查。静态工具不支持局部模式时可检查所属模块或应用，不自动触发全仓测试；不为此开发新工具，也不使用无效参数或削弱配置伪造通过。
- 同一模块相关小修复可集中完成，再统一跑一轮受影响模块验证。修复过程中出现具体新风险时，不以“等批量验证”为由忽略它。
- 受测代码、依赖、配置和相关环境未变，且覆盖仍有效的结果可以复用。文档修改、提交或分支名称变化本身不使结果失效；多项修复集成后只重验失效或尚未覆盖的部分。
- Web 文案、翻译目录或本地化行为变化运行 `pnpm i18n:check`（工作目录 `apps/web`）及对应双语检查。纯规则/文档变更只检查链接、引用、语义一致性与差异，不运行应用测试或安装包构建。

## 扩大验证的唯一触发条件

以下情况才考虑扩大到模块集成或完整回归，并说明依据：

1. 定向测试或具体反例表明影响超出原先范围；
2. 改变公共协议、数据库结构、事务、鉴权或共享基础行为，且无法可靠限定影响；
3. 多项修改集成后的既定验证检查点；
4. 最终冻结 RC 的发布验收；
5. 用户明确要求。

先扩大到受影响模块或消费者，只有这些验证仍不足时再扩大；不直接跳到全仓、全平台、全格式。共享文件变化、迁移或鉴权修改本身不等于完整回归。已冻结 RC 按当前发布门禁验证（code-only 使用[快速发布门禁](../architecture-decisions.md#快速应用更新code-only)，普通发布不变），不能以局部结果替代该门禁；候选版本命名本身不触发重新执行全部测试。

需要相应完整套件时使用既有入口，以下不是每次必跑清单：

- 后端：`cd apps/api-python && uv run --extra dev --locked pytest -q`。
- Web：`cd apps/web && pnpm lint && pnpm typecheck && pnpm test && pnpm test:e2e`。
- Android：[Mobile 工作流](../../.github/workflows/mobile.yml) 的 `run_full_android_regression`。
- iOS：使用既有真机工具链运行受影响测试及发布验收，禁止 Simulator 替代。

## 移动端与设备

需要构建安装包时，按 [移动端开发指南](../mobile-app-development-global-guidelines.md#本地安装包目标与真机执行) 识别宿主并选择目标。共享变更先选择受影响共享测试/消费者契约，在必要阶段构建当前主机对应安装包；同模块相关修复可共用一次验收构建，不因每次修改共享文件反复打包。

设备连接、安装和运行前检查仅适用于设备操作；普通单元或静态检查不要求设备在线。运行缺口如实记录；KMP 测试、其他平台证据和编译结果不代替实际需要的界面/设备验证。宿主分工不修改既有 CI 矩阵，不删除跨平台测试。

按影响选择已有平台单测、仪器测试或手工入口。Android CI 仪器测试入口为 `apps/mobile/scripts/run-android-emulator-tests.sh`；托管 CI 模拟器只作补充，不替代最终物理设备证据。

## 停止、交付与测试真实性

原失败已适当验证、关键相邻行为未破坏、改动范围清楚且没有具体证据指向未解决相关风险时，结束该问题。理论上可能有问题不要求继续找边界、增加诊断或完善工具；具体新反例、真实失败或明确受影响的不变量才触发继续调查。

局部完成简述修复、执行/复用的有效证据、测试范围与具体缺口即可，不强制新建报告体系。未运行全量回归不是局部修复不能完成的理由；局部完成不等于最终发布门禁通过。必需的原失败验证仍缺失时应明确说明，不能声称已验证。

禁止删有效断言、跳过失败、放宽阈值、缩减功能或反复重跑取一次成功。失败须解释和解决；新增 skip、flaky 和静默弱化断言不作为加速手段。删除重复测试前确认没有不同角色、格式、设备、失败和恢复路径；优先保留公开边界清晰、信息有效且成本较低的覆盖。

## 场景核对

| 场景 | 最小充分验证与停止点 | 扩大依据 |
| --- | --- | --- |
| 字段映射 | 原输入到输出的既有测试、缺值/必要反例、模块检查；确认直接消费者正确即停止 | 同一字段其他实际消费者出现失败 |
| 页码显示 | 页码转换边界与原界面显示；不重演导入或同步流程 | 显示修复实际改变导航或位置契约 |
| 缓存条件 | 原覆盖规则、命中/不命中等必要反例及相关存储边界 | 出现取消、并发或命名空间方面的具体新失败 |
| 共享消费者修复 | 同一根因的直接消费者契约；必要时原界面/宿主构建 | 不能可靠限定影响，逐个扩大受影响模块 |
| 遗留 SQL 修复 | 实际查询结果、参数/权限相关反例、受影响接口；不先强制迁移 ORM | 查询契约或事务变化影响无法限定 |
| 定向发现新风险 | 先验证新反例，扩大到实际相关消费者 | 相关模块结果继续证明影响扩大 |
| 同模块批量小修复 | 集中后一次模块验证，复用未失效证据 | 既定集成检查点或新出现的交互影响 |
| 最终冻结 RC | 当前发布门禁要求的完整套件、版本校验及真机证据 | 按既有发布门禁处理，不以局部修复完成代替 |

## 手工验收

按受影响路径选择下列场景，记录版本、环境与未完成项；不继承历史运行结论。

### 书库与部署

- 未登录访问受保护页面进入登录流程；首次设置创建初始管理员，不提供默认密码。
- 在已挂载路径创建 FLAT／VOLUMES 书库，覆盖根文件、多层目录、电子书、图片目录和多轨有声书。对照[书库结构](../library-root-layout.md)核对 Book／Resource／Asset 身份。
- 检查继续导入、部分失败后补齐、自动与手动扫描成功目录的新增／更新／缺失清理一致，失败目录保留原数据；局部范围不访问无关子树，空库保护开关和扫描运行期间后续事件不丢失。
- 上传只写已启用且可写的根目录；目录／资源详情、排序、分页、返回上下文、权限与下载范围正确。
- 数据库启动覆盖空库、当前版本、已知祖先升级、未知或无版本的非空数据库拒绝路径。

### 阅读、下载与收听

- 第一方 Reader v5 的资源入口、进度与书签遵循[当前契约](../architecture-decisions.md#reader-v5-进度)。不同账号／服务器隔离，同一资源精确恢复；展示字段不用于反推 Locator。
- EPUB、FB2、TXT、MOBI 家族完成原文件下载与校验后打开；下载未完成时检查早期字节进度、取消、恢复和迟到结果。完整缓存重开、资产变化与缓存缺失分别检查。
- Web 原始缓存和原生 Download Center 使用各自既有下载所有者；原始长度、哈希与格式不变，不生成持久化派生出版物。
- 章节预览、目录选择、显式章节跳转、空目录和分组条目遵循[统一章节解析](../mobile-reader-architecture.md#统一章节核心)。
- 验证翻页、键盘、点击区、滑动、滚动、正文选择、链接、显示设置和重开恢复；连续操作不积累资源或监听器。
- Web PDF 检查在线 Range；原生 PDF 检查 PDFium 超出易失缓存后的透明原文件物化与原会话切源。漫画检查页加载、缩放、单双页、方向和快速翻页。
- 有声书检查播放／暂停、音轨与章节、seek、倍速、睡眠定时、系统中断、退出与跨账号隔离；冷启动和认证恢复不能自动出声。
- 安全验证检查可读结果、危险副作用缺失与原始字节不变；真实引擎和平台失败不能伪装为内容安全拒绝。

### 平台检查

- Web 同时检查桌面浏览器、真实 iPhone Safari 和主屏幕 PWA；更新提示不在阅读中自动刷新。
- Android 和 iOS 原生应用分别使用物理设备检查安装冷启动、返回、进程恢复、网络、辅助功能和视觉表现。编译与共享测试不能替代各端执行。
- 检查 zh-CN／en-US、深浅色、小屏、大字体、键盘与屏幕阅读器。

以下场景仅定义验收要求，不继承历史通过结论；没有本次有效证据的项目仍需明确记录未验收。

## 专项场景

- 下载面板：浏览／选择／退出、目录折叠保留选择、适用动作计数、入队不等于完成、快速重复提交与部分失败、移除单版本不影响其他版本／服务器文件／阅读记录、失效副本、关闭重开和跨账号过期结果。已接受任务继续；原生面板关闭后再进入本地阅读。已知下载事实不能重建服务器详情。
- 目录面板：异步加载后一次定位、手动滚动保留、重开、展开／折叠、Tab 切换、拖动不翻正文、章节跳转高亮；两端分别检查大字体、横屏、键盘和屏幕阅读器。
- 安全：生成器 --check、boundary checker、真实适配器和样例一致性；检查危险外部请求被阻止、原件字节不变、缓存重开、取消／重试及符号链接逃逸。Chromium/WebKit 与真机 Safari/PWA 分别检查，不用平台缺口推断通过。
- 设置与反馈：OPDS 双向开关即时提交、URL 失焦／点击合并、失败恢复、查看／复制、日志完整导出；保存、标已读、书架、下载入队反馈，重复操作、面板关闭返回、保留错误／Undo、音频和键盘遮挡，以及双语 VoiceOver/TalkBack。

### 在线更新校验变更的定向验证

按[在线更新校验规则](../architecture-decisions.md#在线更新的-sha-256-校验与安装保护)，覆盖真实 GHCR 引用的下载、持久化、确认及离线预检；新增字段和描述性身份/尺寸差异不阻断安装，摘要损坏在替换前拒绝。依赖安装/替换/删除执行器使用生产锁定 uv 版本验证；权限、路径越界、互斥、备份、失败标记和实际服务启动仍需覆盖。发布打包器的严格依赖/布局检查继续验证。此类实现测试不恢复快速发布下载更新或浏览器验收门禁。
