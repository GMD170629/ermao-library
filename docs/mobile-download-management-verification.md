# 图书下载管理验收

本次范围是图书详情的本书／目录／单资源下载面板。下载管线、服务器接口和阅读记录保持既有归属。
Android 真机验收按用户 2026-09-08 的安排延后，由用户自行执行。

## 两端共用场景

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 单文件与资源绑定图书 | 点击详情下载状态 | 大尺寸面板显示本书下载、完成、选择、书名及文件；浏览模式无复选框或批量栏 |
| 多文件与嵌套目录 | 展开目录、进入选择模式、选择文件夹后折叠 | 展开与选择独立；折叠后选择与适用数量保留 |
| 全部已下载 | 选择、全选、取消全选、退出选择 | 已下载文件可以选择移除；退出后清空选择 |
| 混合状态 | 查看单项动作及批量菜单 | 每行仅一个图标按钮：未下载为下载、已下载为删除，进行中禁用下载；暂停和可恢复失败通过下载图标继续／重试。批量动作仅处理适用项目 |
| 队列接受 | 点击下载／继续／重试 | 面板保持打开；提示已接受，进度与完成以真实任务变化为准 |
| 重复点击与状态变化 | 快速重复提交、提交前改变任务状态 | 不重复启动；按提交时事实接受或跳过，并逐项反馈 |
| 批量部分失败 | 使一项操作失败 | 已成功项结果不被覆盖；失败项保留并显示原因 |
| 移除 | 单项或批量移除 | 先确认仅移除本地文件或任务；实际完成后更新数量，不清理阅读记录或服务器文件 |
| 单版本删除 | 下载中心移除一个已有版本 | 不扩大成删除同资源其他版本 |
| 本地副本失效 | 移除或损坏测试副本后重开面板 | 不显示可离线打开；显示失效，远端可用时允许重试 |
| 离线打开 | 点击验证可用文件 | 原生面板完全关闭后进入既有阅读入口 |
| 加载失败与空列表 | 断网打开、目录局部加载失败、成功返回空列表 | 显示明确错误／空状态；局部可重试；已知本地记录限定在当前范围内 |
| 关闭重开 | 加载中关闭、下载接受后关闭再开 | 取消页面加载；已接受下载继续；重开显示当前事实 |
| 账号／服务器切换 | 加载或提交中切换 | 旧结果不能覆盖新页面，旧面板操作不能作用于新账号任务 |
| 文案与辅助功能 | 中文、英文、长标题、大字体、VoiceOver／TalkBack | 文本可读；标题、状态与按钮含义明确；文件夹展开与选择可分别操作 |
