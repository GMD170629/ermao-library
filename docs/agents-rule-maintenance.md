## 第二轮：最小修复与最小充分验证

- 根规则明确直接修复、按行为风险判断、同根因直接消费者检查及停止条件；取消自动迁移、无必要的工具/框架、工作树与多代理复核。
- 工程规范统一中文与层级，目录仅为示例；类型按语义分离，事务由用例决定、适配器实现，副作用和日志只覆盖实际需要；国际化限定本次输出，重构流程按需启动。
- 用户已确认受控遗留 SQL 原位修复例外；新增能力仍使用 ORM/类型化表达式，参数绑定、授权和已发布迁移不可改写要求保持。
- 测试策略明确既有入口优先、同模块批量验证、有效结果复用、五类扩大条件和四项停止条件；不以全量回归缺失阻塞局部完成，也不将局部完成当作发布通过。
- 移动设备清单按实际影响选择，单元测试不要求设备；保留宿主分工与真机政策。手工/专项验收仅增加统一策略入口，不改历史结论或产品语义。
- 发布指南引用既有版本校验脚本并保留其平台覆盖范围；Cursor 与两个仓库 skill 同步执行边界，不新增验证工具或依赖。
