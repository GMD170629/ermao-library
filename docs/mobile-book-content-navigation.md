# Mobile 图书内容导航契约

状态：Accepted，2026-08-27。取代 Mobile Phase 1–3、5 和 ADR 0020 中按资源数量分流、同页切换详情的呈现规则；不修改后端、Web、权限或 Book/Resource/Asset 身份。

## 节点决定页面

Book 是入口。图书根页固定展示 Book 自身的标题、作者、简介和封面；contents 根节点绑定资源时只改变下方阅读内容（音轨、章节等），不得替换图书身份。明确进入下级资源时才显示该 Resource 自身信息。有 resourceId 的节点是资源（即使物理形态是目录）；既有 isSourceFolder 节点是目录。不得按数量、名称、封面、代表资源或阅读历史推断。没有可展示身份的节点报告不可用，不回退到第一个资源。

目录只有一套浏览模板：系统导航标题与返回，其下直接展示数量、六种排序、网格/列表、面包屑、分页和下级封面节点。零个、一个和多个资源不改变页面类型。下级目录不显示大封面身份头部、重复标题、作者、简介、阅读主按钮、进度或独立快捷动作行；不为移除的头部保留空白。“简介”“图书内容”不显示可见区域标题。资源封面进入独立资源详情；资源详情保留其封面身份、简介、当前资源进度、元数据、章节/页预览/音轨和唯一阅读主按钮。显式浏览下级内容与资源主点击分开。

可重排卷册的章节预览来自既有 `reading-units` 接口。服务端在当前 `assetId` 尚无成功目录标记时于该请求内同步解析原文件并返回结果；空目录使用 `chapterCount = 0` 的成功标记。文件重导入或卷册操作发现内容变化时清除该 asset 的目录，下一次访问重新生成。客户端不创建目录任务、不轮询，也不把此服务端目录用于 Reader 正文或精确位置恢复。

图书根页与下级目录使用不同信息密度。图书根页无论绑定目录还是资源，均在内容区上方显示原有图书封面、图书信息、阅读区、下载状态／阅读状态／加入／更多和图书简介。阅读区有进度时显示“正在阅读 · 卷册名称”（音频为“正在收听”）、该卷册进度条和继续阅读／收听按钮；无进度时仅显示开始阅读／收听按钮。不显示多个资源的混合进度。使用现有根入口标识区分布局；下级目录保持精简，图书与卷册详情复用统一操作栏，不新增页面类型、资源中转或导航层。

根页阅读动作使用既有服务端 `continueResourceId`（也包含无历史时的起始卷册），名称和百分比必须来自同一授权资源。缺少资料时通过既有资源分页接口补齐，不根据当前列表、最大进度或代表封面替换目标；目标缺失或不可读时禁用按钮并展示不可用反馈。资源启动不修改目录页的选中资源或页面类型；不传明确章节目标，由 Reader 恢复精确历史位置。已提交的本地阅读进度事件可更新根页阅读目标，按时间顺序合并，返回刷新不得用旧响应覆盖。音频按钮进入当前原生音频会话，播放与恢复遵循[有声书播放器](mobile-audio-player-phase-0-1.md)。

## 导航与动作

目录与资源详情使用原生页面推进，留在来源 Tab；Book 根节点解析不添加中间返回层。面包屑退回已有祖先，系统返回逐层退出。每个目的地保存排序、视图、分页、简介展开及滚动上下文。刷新只更新事实和进度，不重置页面状态；恢复的 ID 必须在当前授权 namespace 下重新验证。

下级目录下载保留在系统导航栏“更多”菜单，仅覆盖当前子树。每个平台只有一套详情操作栏：图书根页为下载状态／阅读状态／加入／更多；卷册详情按同一组件配置资源操作，不重复图书级加入。**操作对象始终是当前页面对象**：图书页的下载和阅读状态作用于整本 `bookId`，更多与加入也作用于图书；卷册页作用于当前 `resourceId`。即使图书直接绑定单资源，图书入口仍保留图书级操作身份。只有主阅读按钮单独解析书中上次阅读的卷册／位置，不把它作为整套操作栏对象。

图书下载按钮显示该书全部本地任务的状态，点击进入统一“本书下载”管理面板；已下载数量只统计验证通过的资源，不把一卷下载完成称为整书完成。图书、下级目录和卷册入口复用此面板，分别限定整书、当前子树和当前资源的操作范围。图书阅读状态使用既有整书接口，卷册状态使用资源接口；成功后清除对应范围的旧阅读投影并刷新，失败不伪装为已更新。根页保留书架与 Book 管理且导航栏不重复菜单。权限过滤、确认与失败反馈不变。代表封面不成为默认阅读目标。显式章节/页目标优先于历史进度，交给 Reader 校验；无目标时沿用既有恢复策略。Reader 原始格式及 v5 进度身份遵循[Reader 架构](mobile-reader-architecture.md)。

## 本书下载管理

iOS 和 Android 使用各自的原生大尺寸面板，遵循同一浏览／选择流程。
默认浏览显示简洁书名说明、目录层级、资源原始标题和真实状态；长标题最多两行，不通过裁剪公共前缀生成新身份。行内主操作复用共享 primaryAction：未下载为下载，排队／下载中为暂停，暂停为继续，可恢复失败为重试，验证完成为打开；移除放在更多菜单并保留二次确认。按钮沿用当前中性色，不额外使用系统动态主题色或设计稿中的橙色按钮。状态文字和下载进度独立展示，失败显示已有本地化原因；状态文字不兼作隐藏菜单入口。

选择模式顶部显示已选数量、一个退出选择入口与全选／取消全选；底部突出当前可用的批量动作，其余可用动作放在更多菜单，无适用目标时禁用主按钮。混合选择的动作计数和确认范围均来自共享策略筛选结果。仅所选资源的大小全部已知时显示合计大小。退出选择模式清空选择；已下载内容仍可选中用于移除，目录展开与选择是独立操作。两端保持原生面板和系统安全区，面板底部不露出第二条可见的 App Tab 操作区。
KMP `DownloadManagementPolicy` 是两端状态、可用动作、批量目标和选择标记的共同 owner。
平台将已有 catalog、验证结果和运行中任务映射为事实；不在 UI 重新定义业务资格。
操作前以当前事实重新验证资源范围和动作资格。批量下载／继续／重试的 Accepted
仅表示任务已接受，不能提示传输完成或自动关闭面板；暂停和移除等待操作完成，
逐项保留失败结果。移除只影响本地下载或任务，不删除服务端图书和阅读记录。

已完成但未验证的本地记录显示失效状态，通过现有下载 owner 重试；只有验证通过的
本地副本可打开。离线打开先关闭管理面板，再交给已有 Reader 入口。关闭面板取消
页面请求，不取消已接受的下载；加载失败保留已知下载事实并提供重试，但不能用其
重建服务器详情。账号／服务器切换必须取消旧加载并拒绝旧结果。

音频资源详情与音轨展示连接原生播放器。可重排阅读入口按 ADR 0025 隐式创建／观察卷册原文件下载任务，完整校验后由本地 Reader 打开；漫画保持在线交付；原生 PDF 按 PDFium 请求与缓存条件选择在线 Range 或透明原文件物化，见 [ADR 0027](adr/0027-pdfium-transparent-original-materialization.md)。

## 验收

覆盖目录/文件绑定资源、零/一/多资源目录、多层返回、分页与滚动恢复、快速点击与过期请求、章节定位、授权变化、下载范围、双语/深浅色/大字体/辅助功能。Android 和 iOS 分别使用物理设备验收；编译和模拟器不能替代真机证据。

## 手动阅读状态

手动设为已读显示 100%，设为未读显示 0%。两者都不保存阅读位置，再次打开均从头开始，不生成书尾定位。服务器在现有状态写入事务中移除旧阅读定位，本地使对应位置与待同步缓存失效；后续实际阅读继续使用正常进度保存和同步流程。图书级操作覆盖本书资源，资源级操作只覆盖该资源，不删除书签、下载文件或偏好。

## 元数据归属与封面版本

Web、iOS、Android 只展示当前对象的接口字段，不跨 Book、Resource、SourceNode 回退。缺失封面以缺省占位展示，缺失简介不借用其他对象正文。服务端封面查询同样只解析对象自己的真实封面；资源有封面不代表图书有封面，补齐归属现有元数据识别队列，读取页面不得触发补齐写入。

真实封面 URL 携带服务端生成的 `v` 文件身份版本，尺寸转换保留版本。原生缓存只有带版本地址可以跳过网络；旧服务器无版本地址需重新验证。版本变化或 URL 变为空时清除旧图。默认图响应不是有效封面，不进入真实封面缓存。详情身份一致性样例见 [测试样例](testing/fixtures/book-detail-identity.json)。
