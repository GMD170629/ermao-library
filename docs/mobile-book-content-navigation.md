# Mobile 图书内容导航契约

状态：Accepted，2026-08-27。取代 Mobile Phase 1–3、5 和 ADR 0020 中按资源数量分流、同页切换详情的呈现规则；不修改后端、Web、权限或 Book/Resource/Asset 身份。

## 节点决定页面

Book 是入口。读取既有 Book 和 contents 合同后，绑定目录显示目录内容页，绑定可读资源显示资源详情。根节点和下级节点遵循同一规则：有 resourceId 的节点是资源（即使物理形态是目录）；既有 isSourceFolder 节点是目录。不得按数量、名称、封面、代表资源或阅读历史推断。没有可展示身份的节点报告不可用，不回退到第一个资源。

目录只有一套浏览模板：系统导航标题与返回，其下直接展示数量、六种排序、网格/列表、面包屑、分页和下级封面节点。零个、一个和多个资源不改变页面类型。下级目录不显示大封面身份头部、重复标题、作者、简介、阅读主按钮、进度或独立快捷动作行；不为移除的头部保留空白。“简介”“图书内容”不显示可见区域标题。资源封面进入独立资源详情；资源详情保留其封面身份、简介、当前资源进度、元数据、章节/页预览/音轨和唯一阅读主按钮。显式浏览下级内容与资源主点击分开。

2026-08-27 后续确认：仅恢复“点击图书进入的根页”。绑定目录的图书根页在浏览区上方显示原有图书封面、图书信息、阅读区、下载状态／阅读状态／加入／更多和图书简介。阅读区有进度时显示“正在阅读 · 卷册名称”（音频为“正在收听”）、该卷册进度条和继续阅读／收听按钮；无进度时仅显示开始阅读／收听按钮。不显示多个资源的混合进度。使用现有根入口标识区分布局；下级目录保持精简，图书与卷册详情复用统一操作栏，不新增页面类型、资源中转或导航层。

根页阅读动作使用既有服务端 `continueResourceId`（也包含无历史时的起始卷册），名称和百分比必须来自同一授权资源。缺少资料时通过既有资源分页接口补齐，不根据当前列表、最大进度或代表封面替换目标；目标缺失或不可读时禁用按钮并展示不可用反馈。资源启动不修改目录页的选中资源或页面类型；不传明确章节目标，由 Reader 恢复精确历史位置。已提交的本地阅读进度事件可更新根页阅读目标，按时间顺序合并，返回刷新不得用旧响应覆盖。音频按钮展示开始／继续收听，同时注明手机端播放暂不支持，点击保留明确提示。

## 导航与动作

目录与资源详情使用原生页面推进，留在来源 Tab；Book 根节点解析不添加中间返回层。面包屑退回已有祖先，系统返回逐层退出。每个目的地保存排序、视图、分页、简介展开及滚动上下文。刷新只更新事实和进度，不重置页面状态；恢复的 ID 必须在当前授权 namespace 下重新验证。

下级目录下载保留在系统导航栏“更多”菜单，仅覆盖当前子树。每个平台只有一套详情操作栏：图书根页为下载状态／阅读状态／加入／更多；卷册详情按同一组件配置资源操作，不重复图书级加入。**操作对象始终是当前页面对象**：图书页的下载和阅读状态作用于整本 `bookId`，更多与加入也作用于图书；卷册页作用于当前 `resourceId`。即使图书直接绑定单资源，图书入口仍保留图书级操作身份。只有主阅读按钮单独解析书中上次阅读的卷册／位置，不把它作为整套操作栏对象。

图书下载按钮显示该书全部本地任务的状态，点击进入既有整书资源树下载管理；已下载数量只统计验证通过的资源，不把一卷下载完成称为整书完成。卷册下载按钮继续提供该卷册的下载、暂停、重试和已下载管理。图书阅读状态使用既有整书接口，卷册状态使用资源接口；成功后清除对应范围的旧阅读投影并刷新，失败不伪装为已更新。根页保留书架与 Book 管理且导航栏不重复菜单。权限过滤、确认与失败反馈不变。代表封面不成为默认阅读目标。显式章节/页目标优先于历史进度，交给 Reader 校验；无目标时沿用既有恢复策略。Reader 原始格式、v4 协议和进度身份不变。

本轮音频只提供资源详情和音轨展示，播放操作明确提示手机端暂不支持；不实现播放器，也不模拟成功。可重排阅读入口按 ADR 0025 隐式创建／观察卷册原文件下载任务，完整校验后由本地 Reader 打开；PDF／漫画保持在线交付。

## 验收

覆盖目录/文件绑定资源、零/一/多资源目录、多层返回、分页与滚动恢复、快速点击与过期请求、章节定位、授权变化、下载范围、双语/深浅色/大字体/辅助功能。Android 和 iOS 分别使用物理设备验收；编译和模拟器不能替代真机证据。
