# ADR 0030：文件导入与图书元数据收尾

- 状态：Accepted
- 日期：2026-09-10
- 授权：用户确认两阶段导入方案并要求实现。

文件任务只写 Asset 与 Resource，Book 在所属路径范围的文件任务和相关扫描均结束后识别。失败任务为终态，不阻塞本地识别；取消不触发收尾。任务、修订及待识别状态持久化，复用现有单消费者队列。

Book 按用户 SIDECAR_OPF／EMBEDDED／PATH 优先级逐字段合并。只有一个已启用资源时允许使用该资源候选；多资源不继承子卷文本。名称解析只看自身名称，支持明确作者标记和“书名 - 作者”，不推断父目录。人工编辑（含清空）受保护。

Book 自有封面缺失时先选定按路径排序的第一个可读资源，再验证其封面；该封面不存在或无效时使用默认展示，绝不跳到后续资源。默认图不作为真实封面写入。导入收尾与整本重新生成复用此选择规则。

本地识别必跑，联网遵循自动整理设置。文件导入状态和元数据处理状态分离；联网失败保留本地结果。所有读取继续遵循 ADR 0029，不增加全文或全媒体检查。

## 持久契约与入口

名称解析也支持完整的 `[书名][作者]` 文件名或目录名：去除已知文件扩展名后匹配两个非空方括号字段，允许字段内外空白，再沿用卷号解析。多组括号或缺失字段不按该格式猜测作者。

复用 `LibraryImportTask`，新增 `IDENTIFY_BOOK`。BookMetadata 记录 `importRevision`、`processedRevision`、`metadataPending`、`metadataState`；活动识别任务对 Book 根节点有唯一约束，并记录执行修订。终态检查与识别入队同事务协调，写回前校验修订、人工编辑时间和本地来源优先级。

Book 响应继续使用原查询入口，新增 `metadataState`（WAITING_IMPORT／QUEUED／RUNNING／COMPLETED／FAILED）、`metadataPending` 与 `metadataOnlineState`。既有 `resourceImportSummary` 新增 `failedFiles`，表示失败的文件任务数；它与卷册 `failed` 独立，覆盖卷册已可读但部分音轨失败的情况。

Asset 仅保存有界的按来源元数据候选和封面引用，不保存正文。文件封面以独立版本发布后再提交引用；失败或取消时撤回新版本，保留原封面。Book 封面沿用带备份的根节点发布机制。新增迁移 0010，不修改已发布迁移，也不回填旧业务数据。
