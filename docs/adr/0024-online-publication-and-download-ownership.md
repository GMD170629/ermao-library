# ADR 0024: 在线 Publication 与显式下载的独立所有权

- 状态：采用；设备与性能验收尚未全部完成
- 日期：2026-08-28
- 范围：Web、Android、iOS、Publication 后端与共享 Downloads
- 关联：ADR 0014、0016、0020；`mobile-reader-architecture.md`

## 决策

普通在线 Reader 只访问原始格式的 manifest、positions、当前完整章节及其资源、漫画页或 PDF Range，不下载整本、不后台补齐。Web 保持原有严格在线策略。原生 App 的明确在线大小／解析预算限制及 Range 不支持允许进入独立下载过渡页，由账号持有的 Downloads 唯一实现负责完整下载，然后打开已验证原文件。鉴权、损坏、版本变化和普通网络错误不分流；已知本地引擎不能处理时直接失败。无章节 TXT 仍是一个完整阅读单元，不通过虚拟分章规避限制。

原生统一文件准入上限为 2 GiB（含边界），由 KMP ReaderAdmission 拥有并通过参数传入原生 C；目录资源累计成员大小，长度／偏移用 64 位。准入不代表引擎一定能打开。接受既有整文件解析和整章加载带来的卡顿或内存失败，不新增索引、增量解析、转换或深度 SDK 补丁；独立 XML、图片、解压和分配限制保留。无法可靠捕获的系统内存终止不承诺优雅恢复。

服务器可以首次解析已有原文件，不要求用户预先完成导入索引。EPUB 使用原包目录；TXT/FB2 只为请求章节生成 XHTML；MOBI 同一文件版本共用一个受租约保护的原生解析实例。PublicationRuntime 由应用生命周期拥有，解析缓存有容量、失效、并发与关闭规则。资源版本由服务端返回并在消费正文前校验；HEAD 只返回元数据。

| 内容 | 请求与驻留规则 |
| --- | --- |
| 重排文本 | 一个完整章节最多 8 MiB；只保留当前及紧邻章节；辅助资源单项最多 32 MiB |
| 漫画 | 原始分页接口；当前页及相邻页，不获取整本归档 |
| PDF | 每个 Range 最多 1 MiB；忽略 Range 的 200、长度错误与版本变化在读取正文前取消 |
| 应用持有的在线正文 | 应用缓存最多 64 MiB；切换单元淘汰旧内容，关闭、切书和退出账号释放；原生 SDK 允许常规缓存，不为精确总预算深改 SDK |

Android/iOS 复用 KMP 的 OnlinePublicationSession、PdfRangeLoader、鉴权、响应流、版本校验、取消和缓存策略。原生 Readium 容器与 PDFium 只绑定资源、渲染及映射定位。Web 通过 feature API adapter 请求同一合同；固定版本的 Readium TS/PDF.js 补丁负责限制 SDK 内部预取和缓存，真实 SDK 回归测试是升级前置条件。

## 显式下载

Downloads 拥有唯一下载工作流：DownloadResourceRuntime 负责串行任务入口、去重、恢复、状态和完成登记；KtorDownloadsGateway 负责唯一原文件传输机制。单项、批量、下载中心均调用同一入口。IMAGE_DIR 只保留多资源组织差异，成员文件使用相同传输路径。平台适配器只提供存储、通知与生命周期。

下载的原文件版本使用服务端 `X-Asset-Version` 合同校验，暂停续传不能混合不同版本。临时文件通过验证后原子发布，完成记录才可被 Reader 的只读 Downloads 接口解析为离线来源。Web 从资源描述获取原文件下载地址并交给浏览器保存，不启动 Reader 获取下载描述，也不新增文件下载引擎。

原生 Reader 启动协调可通过 Downloads 公共应用接口发起或观察已有任务。过渡页显示封面、书名、原因、真实字节／百分比、取消和重试；排队及解析不伪造进度。已验证文件不重复下载且直接离线打开。取消撤销自动打开意图，本次启动的任务暂停保留续传数据，已有独立任务只解除观察；账号变化及页面关闭禁止迟到打开。下载完成仍在下载中心可管理；章节目标及现有进度沿用唯一 Reader 进度体系。下载后解析失败不得重复下载或在线／本地循环。

迁移必须切换所有调用并删除旧业务实现、公开别名、空壳代理、状态、双语文案与装配；本能力不保留兼容下载入口。实现前先检索现有行为，重复业务流程不能以平台差异为理由保留。

## 数据保留

仅清理能确认由旧自动在线流程生成的副本及临时文件。主动下载、本地导入、书签和进度不能被缓存迁移删除。当前有效进度保留原身份与定位含义；无法确认账号/资源身份的历史文档保留但不自动归属到当前账号。Android 旧字段升级通过事务复制保留文档，精确进度不因令牌代次轮换而丢失；待同步写入仍按授权代次隔离。

## 验证

验收要求覆盖阻断其他章节仍可读、无原文件请求/下载任务/后台补齐、取消未完成响应、版本变化、超限、并发解析复用、缓存淘汰和显式下载恢复。代码、单元测试和服务器测量不替代真机证据。

原在线链路证据见 `../verification/2026-08-27-streaming-reader/README.md`；本版在线优先、下载过渡及 2 GiB 准入证据见 `../testing/mobile-reader-online-first-2026-08-28.md`。未完成 iOS 真机或 Android 复测时，不得标记全端验收通过。
