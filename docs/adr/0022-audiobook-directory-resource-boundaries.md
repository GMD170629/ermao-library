# ADR 0022：有声书目录资源边界与音轨元数据

- 状态：已接受
- 日期：2026-08-24
- 修订：[ADR 0018](0018-physical-source-tree-book-readable-resource-overlay.md) 中目录 Resource 对重叠子树的所有权规则

## 背景

ADR 0018 使用“最外层目录 Resource 拥有整个后代子树”的通用规则。对有声书而言，这会把作品目录下多个分卷的全部音频聚合为一个 Resource，并丢失音轨时长、标题和编码等解析结果。播放器随后只能显示“音轨 N”，总时长也只能依赖浏览器逐轨加载。

## 决策

- `VOLUMES` 的第一级目录仍是 Book 锚点；其下每个实际拥有直属音轨的普通目录分别成为 ReadableResource。
- 有声书目录 Resource 只拥有直属音轨，以及中间路径全部为 `CD`、`Disc`、`Disk`、`碟`、`盘` 及其编号形式的音轨。
- 普通目录是不可穿透的资源边界。父目录仅有普通子目录音轨时保持 `NODE_ONLY`；扫描器继续探测子目录。
- 父目录同时有直属音轨和普通子目录时，父目录自身形成一个 Resource，标题使用该目录名；普通子目录继续形成独立 Resource。
- `FLAT` 使用同一资源边界，但每个识别出的目录 Resource 建立自己的 Book。
- 图片目录及其他目录适配器继续使用既有规则。
- 所有 `audiobook-directory` Resource 统一使用这套边界，不根据资产数据状态或 adapter 版本选择不同规则。
- 音频解析成功后持久化内嵌标题、MIME、时长、编码、码率、采样率、声道、碟号和轨号。资源总时长、音轨数和章节数只从 READY TRACK 资产重算。
- 展示标题使用资源内唯一且非泛化的内嵌标题；否则回退原文件名。单轨标题不得覆盖 Book 或 Resource 标题。

## 后果

多卷有声书按物理分卷形成多个可读资源，播放器无需逐轨加载即可得到标题与整卷时长。本决策不为既有数据、既有资源形态或 adapter 版本提供兼容分支。
