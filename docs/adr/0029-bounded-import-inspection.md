# ADR 0029：导入仅执行有限信息读取

- 状态：Accepted
- 日期：2026-09-10
- 授权：用户明确批准的导入与扫描有限读取计划

## 决策

扫描和导入允许文件系统属性、元数据、目录、封面、必要页码以及有限编码样本。
禁止全文解码、全页完整性预检、全文正则搜索、全媒体包或块计数，以及解析失败后的全文件修复扫描。
分块读取、后台执行和限时执行不构成例外。上传原件保存和实际阅读、播放不属于导入探测。

通用结构探测每文件累计 8 MiB；元数据文档复用 2 MiB 上限，指定封面复用 20 MiB，
编码样本不超过 4 MiB 加 3 字节。漫画结构和页资源安全限制继续由 ADR 0026 的机器契约拥有。
这些探测预算限制工作量，耗尽时保留已知结果，不构成出版物拒绝规则。
有限头尾样本自然覆盖小文件不等于主动扫描全文。

未取得的页数、时长、技术信息保持 null；目录和封面可缺失。READY 表示已登记、可以尝试打开，
不代表所有正文已经验证。缺失文件、访问错误与已确认的安全违规保持既有失败语义。
重新导入清除失效技术值和导航，不改写用户描述性元数据；任何音轨时长未知时，总时长未知。

PDF 不执行文字分类、损坏索引恢复或虚构一页；TXT 不校验全文和 NUL 尾部；FB2 到 description 结束即停止；
MOBI 按记录表定位元数据和封面；压缩漫画不读取普通页载荷，保持坏页位置。ZIP/CBZ 导入仅使用中央目录登记页面，不逐成员预读本地文件头或预先计算数据区间重叠。
封面、元数据及实际请求的页面由 ZIP SDK 在打开和读取成员时执行结构与完整性检查；
重叠页面可能被登记，实际阅读失败时按现有 Reader 规则阻止该页并保留页位置。
此调整不移除机器契约中的重叠完整性规则，也不要求批量重导历史资源。
RAR 导入不提取成员内容，
避免固实块与外部解压后端的隐式遍历。音频导入不运行 ffprobe，仅保留核验过的受限标签入口；
没有安全入口的格式仍登记资产，信息未知。不得因为缺少时长将其标为解析失败。

Reader 实际资源访问继续执行 ADR 0026 的完整性、容量和解码规则，原件交付仍遵循 ADR 0025/0027。
禁止把导入成功当作跳过 Reader 安全检查的依据。本决策不修改原有 Reader 阈值和生成绑定。

## 验证与发布

以真实读取区间、累计字节及禁止正文访问的样本验证 SDK 和适配器，不以函数名称或编译通过替代。
覆盖首次、重导、重试、取消与事务回滚。后端更新后用于后续任务；不强制批量重导历史书库，
不放宽 500ms 后台写事务限制。
