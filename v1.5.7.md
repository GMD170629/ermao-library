# v1.5.7

<!-- shuku:locale=zh-CN:start -->
## 修复：

1. 图书与音频的新文件导入统一为单文件最多 2 GiB，取消上传批次及音频目录的合计大小限制，并统一超限提示；已入库的大文件仍可继续阅读。
2. 取消 Web 阅读器和服务端对 EPUB、TXT、FB2、MOBI/AZW/AZW3/PRC 的正文、目录、内嵌图片及资源大小和数量限制，修复大文件或大章节被提示超过可解析限制的问题。
3. 取消漫画清单大小、页数、单页大小及压缩包展开量限制，修复大漫画目录无法加载和部分页面被旧限制过滤的问题。
4. 取消音频曲目数、章节数、元数据及内嵌封面大小限制，以及 Web PDF 阅读器的页数上限。
5. 修复部分 MOBI/AZW3 图书缺少可选目录锚点等信息时无法打开的问题，恢复正文阅读、目录跳转和缓存重开。

## Fixed:

1. New book and audio imports now share a 2 GiB per-file limit. Removed aggregate size limits for upload batches and audio directories, and standardized oversized-file messages. Previously imported large files remain readable.
2. Removed content-size and count limits for text, navigation, embedded images, and resources in EPUB, TXT, FB2, and MOBI/AZW/AZW3/PRC books in the web reader and server, fixing parsing-limit errors for large files and chapters.
3. Removed comic manifest, page-count, individual-image, and expanded-archive size limits, fixing failed navigation loading for large comics and pages omitted by the previous limits.
4. Removed audio track-count, chapter-count, metadata-size, and embedded-cover limits, along with the web PDF reader's page-count limit.
5. Fixed MOBI/AZW3 books failing to open when optional information such as a table-of-contents anchor is absent, restoring reading, chapter navigation, and reopening from the local cache.
