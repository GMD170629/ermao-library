# v1.1.0

## 新增与改进

- 支持在关于页下载并安装应用更新。管理员可先准备更新包，下载期间不停止服务；准备完成后，再确认安装并重启应用服务。
- 更新检查、下载进度、校验、安装结果和错误提示统一显示在一个状态条中。发现新版本时显示橙色提示，下载并校验完成后提供“立即更新”；刷新页面后可继续查看更新状态。
- 更新前明确提示暂停队列领取、等待正在运行的任务结束以及服务暂时不可用。取消确认不会安装，网络断开后会继续核对更新状态，避免重复提交安装。
- 兼容部署可复用未变化的依赖，仅下载需要变更的依赖包，减少更新下载量。安装前校验更新包和运行环境，并在停止业务后备份数据库。

## 升级说明

- 旧版本尚无应用内更新入口时，请先通过原有 Docker 或 fnOS 部署方式升级，保留原有数据与书库挂载；应用内更新仅对支持该能力且运行环境兼容的部署开放。
- 安装更新会暂时中断服务，请勿关闭容器或设备。遇到环境不兼容或安装失败时，请按提示检查部署和日志，不要清空数据库。

## Features and improvements

- Download and install application updates from the About page. Administrators can prepare an update without stopping services, then separately confirm installation and an application service restart.
- Update checks, download progress, verification, installation results and errors now share one status bar. New versions appear in orange; once the package is downloaded and verified, Update now becomes available. Refreshing the page restores the update status.
- Installation confirmation explains that queue processing will pause, running tasks must finish and services will be temporarily unavailable. Cancelling does not install anything. After a connection loss, the app checks the installation outcome instead of submitting it again.
- Compatible deployments reuse unchanged dependencies and download only dependency packages that need to change. Updates verify packages and the runtime environment before installation, then back up the database after application activity stops.

## Upgrade notes

- If your current version has no in-app update action, first upgrade through your existing Docker or fnOS deployment method while retaining your data and library mounts. In-app updates require a supported deployment and a compatible runtime environment.
- Installation temporarily interrupts service. Do not stop the container or device. If the environment is incompatible or installation fails, follow the deployment and log guidance rather than clearing the database.
