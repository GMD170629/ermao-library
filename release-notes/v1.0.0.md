# v1.0.0

<!-- shuku:locale=zh-CN:start -->
## 简体中文

二毛图书现已进入 v1.0.0 正式版本。Web、服务端、Android、iOS 与共享阅读组件统一采用 1.0.0 版本标识，形成一致的部署、诊断和客户端展示基线。

本次版本整理保留既有书库管理、导入、阅读、进度同步与移动端体验，并将正式版本信息同步到运行时配置、安装包元数据和前端资源缓存标识。此次提交只在 develop 分支准备版本，不创建发布分支、不打标签，也不执行发布。

## English

Ermao Library now carries the v1.0.0 stable version identity. The web app, server, Android app, iOS app, and shared reader packages use the same 1.0.0 version baseline for deployment, diagnostics, and user-visible version information.

This version preparation preserves the existing library, import, reading, progress-sync, and mobile experiences while synchronizing runtime configuration, application package metadata, and frontend cache identity. The change is prepared only on develop: it does not create a release branch, tag, or published release.
