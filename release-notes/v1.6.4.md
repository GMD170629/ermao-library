# v1.6.4

<!-- shuku:locale=zh-CN:start -->
## 新增：

1. 将「空间管理」和「网络与代理」纳入「数据和系统」，与「备份与恢复」并列显示。
2. 支持为服务器出站请求配置 HTTP 或 SOCKS5 代理。可使用版本更新、GitHub 和 Bangumi 预设，也可添加自定义域名。
3. 「网络与代理」在代理留空时也能测试服务器连通性。进入「关于」页时，「检查更新」会先检测能否访问官方更新源，失败时提示设置代理或检查网络。

## 修复：

1. 下载更新途中断开连接时，显示连接中断或超时提示，便于检查网络后重试。
2. 修复切换同版本容器镜像后可能继续运行旧程序的问题。
3. 修复用键盘选择 SOCKS5 时，静止的鼠标指针可能让协议选项切回 HTTP 的问题。

<!-- shuku:locale=en-US:start -->
## Added:

1. Storage management and Network & Proxy now appear alongside Backup & Restore under Data & System.
2. Configure an HTTP or SOCKS5 proxy for outbound server requests using presets for version updates, GitHub, and Bangumi, or add custom domains.
3. Test server connectivity with the proxy fields left blank. The About page checks access to the official update source before enabling Check for updates, and shows guidance if the check fails.

## Fixed:

1. Interrupted or timed-out update downloads now show the corresponding network message so you can check the connection and retry.
2. Fixed an issue where switching to a different container image with the same version could keep running the old application.
3. Fixed the proxy protocol switching back to HTTP when a stationary mouse pointer interfered with keyboard selection of SOCKS5.
