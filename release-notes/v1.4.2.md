# v1.4.2

<!-- shuku:locale=zh-CN:start -->
新增：

1. 大型书库按图书独立导入。目录仍在扫描时，已发现的图书可以先完成导入；再次扫描只处理变化的文件，减少等待和重复解析。
2. 失败的导入任务可以创建独立的重新导入任务，原任务结果仍可查看；任务列表显示整本图书的导入状态。

修复：

1. 导入中断或部分资源失败时，保留已成功的资源和阅读位置，其他图书仍可继续处理。
2. 减少重复封面处理，漫画页改为按需解析，降低大型导入和浏览时的不必要工作。
3. 修复 SMTP 连接测试与保存设置使用不同请求字段的问题。

注意事项：

1. 本次包含数据库迁移，支持应用内在线升级，无需仅因迁移更换镜像。升级前请自行备份数据库和存储；如需回退，须同时恢复匹配的旧应用、数据库及存储备份。

<!-- shuku:locale=en-US:start -->
Added:

1. Large libraries now import each book independently. Discovered books can finish while the directory scan continues, and later scans process changed files to reduce waiting and repeated parsing.
2. Failed imports can start a separate reimport task while preserving the original result; the task list shows the status of each whole-book import.

Fixed:

1. An interrupted import or failed resource keeps previously completed resources and reading positions while other books continue processing.
2. Reduced duplicate cover processing and resolved comic pages on demand, avoiding unnecessary work during large imports and browsing.
3. Fixed inconsistent request fields between saving SMTP settings and testing the SMTP connection.

Notes:

1. This release includes database migrations and supports the in-app online update; the migrations alone do not require a new image. Back up the database and storage before upgrading. A rollback requires the matching older application, database, and storage backup together.
