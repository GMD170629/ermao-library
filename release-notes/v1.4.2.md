# v1.4.2

<!-- shuku:locale=zh-CN:start -->
## 改进

- 大型书库导入现在按图书推进。目录仍在扫描时，已确认的图书可以先完成导入；再次扫描只处理发生变化的文件，减少等待和重复解析。
- 导入中断或部分文件失败后，继续处理会保留已成功的资源和阅读位置；上传后的导入进度也会显示整本图书的真实任务状态。

## 升级说明

- 本版本包含数据库升级，请使用完整服务端更新。升级前确认数据库及存储备份；如需回退，必须同时恢复匹配的旧应用、数据库和封面／存储备份。仅回退应用镜像无法安全使用升级后的数据库。

## Improvements

- Large library imports now advance one book at a time. Books already discovered can finish while the directory scan continues, and later scans process only changed files to reduce waiting and repeated parsing.
- After an interruption or partial file failure, continuing the import preserves successful resources and reading positions. Upload progress now reflects the book's actual import task state.

## Upgrading

- This version includes a database migration and requires a full server update. Confirm database and storage backups before upgrading. To roll back, restore the matching older application, database, and cover and storage backups together; reverting only the image is unsafe with the upgraded database.
