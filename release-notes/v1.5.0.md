# v1.5.0

<!-- shuku:locale=zh-CN:start -->
## 新增：

1. 增强图书与卷册元数据识别，结合标题、作者、ISBN 和版本信息核对候选，支持人工确认与受控 AI 查询辅助。
2. 新增 Google Books、Open Library 元数据来源，完善来源配置、识别记录和字段应用反馈。
3. 移动端设置页新增头像、用户名和退出登录入口，统一账户操作布局。
4. Android 阅读器支持沉浸式阅读，正文、工具栏、目录和设置中隐藏顶部系统状态栏，并优化顶部留白。

## 修复：

1. 修复元数据候选的作品、卷册和版本范围判断，减少同名作品、不同作者或不同版本信息混用；过期结果不能覆盖后续修改。
2. 简化移动端退出确认弹窗；普通退出保留已下载图书及阅读进度，同一服务器、同一账号重新登录后可继续阅读，未完成下载可手动继续。
3. 修复图书详情元数据的展示与刷新，改善移动端和网页端的一致性。
4. 改善管理日志中的异常原因展示与导出，便于定位操作失败。

## Added:

1. Enhanced book and volume metadata recognition with title, author, ISBN and edition checks, manual confirmation and bounded AI-assisted queries.
2. Added Google Books and Open Library metadata sources, with improved source settings, recognition records and field application feedback.
3. Added avatars, usernames and sign-out controls to mobile settings with a consistent account layout.
4. Added immersive Android reading: the top system status bar stays hidden in reading, toolbars, contents and settings, with reduced top spacing.

## Fixed:

1. Improved work, volume and edition matching to prevent mixing similarly named books, different authors or editions; stale results cannot overwrite later changes.
2. Simplified mobile sign-out confirmation. Normal sign-out preserves downloaded books and reading progress for the same account on the same server; unfinished downloads can be resumed manually.
3. Fixed metadata display and refresh on book details, improving consistency across mobile and web.
4. Improved error details and export in administration logs to help diagnose failed operations.
