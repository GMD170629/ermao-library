# v1.0.3

<!-- shuku:locale=zh-CN:start -->
## 修复与改进

- 图片目录和 PDF 缺少有效元数据封面时，自动使用阅读页序第一页或 PDF 物理第 1 页作为封面。新导入自动生效，已导入资源可使用“重新生成封面”更新；保留人工封面保护，首页损坏时不跳到后续页。
- Web 阅读器支持普通 HTTP 环境下的原文件存储与完整性校验。原文件改用账号隔离的 IndexedDB 分块保存，完整下载并校验后才打开，取消、失败、退出登录或权限变化不会发布未完成内容。
- 原文件缓存命中后无需重复下载；升级时清理旧 Reader 缓存，原件首次打开需重新下载。HTTP 和 HTTPS 均保留章节及 MOBI 运行文件的 SHA-256 校验。
- 源码包含 iOS 会话过期后复用完整登录表单及 KMP 管理枚举兼容修正；本次不构建或提供手机端安装包，这些改动将在后续手机端交付中生效。
- 本次发布提供 amd64/arm64 Docker 镜像、fnOS FPK 及 SHA-256 校验文件，不执行手机端构建 workflow，不提供 v1.0.3 APK 或 IPA。移动端源码版本同步至 1.0.3（构建号 4），现有手机端安装包保持不变。

## Fixes and improvements

- Image directories and PDFs without valid metadata artwork now use the first reading-order image or physical PDF page 1 as their cover. New imports apply this automatically; existing resources can use Regenerate cover. Imported updates preserve manually protected covers, and an unreadable first page never falls through to later pages.
- The Web reader now supports original-file storage and integrity checks over plain HTTP. Account-isolated IndexedDB stores bounded chunks and publishes files only after complete download and validation. Cancellation, failures, sign-out, and authorization changes cannot publish incomplete content.
- Cached originals reopen without another download. Upgrading removes the legacy Reader cache, so originals download again on first use. Chapter and MOBI runtime SHA-256 checks remain enforced on both HTTP and HTTPS.
- The source includes a unified iOS login form for expired sessions and corrected exported KMP management enum names. These changes will reach devices in a future mobile build; this release does not build or distribute mobile installers.
- This release provides amd64/arm64 Docker images, the fnOS FPK, and SHA-256 files. Mobile build workflows are skipped, and no v1.0.3 APK or IPA is provided. Mobile source versions are synchronized to 1.0.3 (build 4); existing mobile installers remain unchanged.
