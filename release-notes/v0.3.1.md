# v0.3.1

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本重点升级书库与书架浏览：首页、全部图书和书架详情采用响应式实体书架陈列，并支持滚动连续加载。

后端新增小尺寸 WebP 封面缓存，在保持清晰度的同时降低书架页面的图片传输开销；书架摘要与详情接口也针对分页加载进行了优化。

同时完善中英文文案、移动端布局与跨浏览器回归测试。

## English

This release upgrades library and shelf browsing. The home page, all-books view, and shelf details now use responsive physical-shelf layouts with continuous loading while scrolling.

The backend adds small WebP cover caching to reduce shelf image transfer while preserving clarity, and shelf summary and detail APIs are optimized for paginated loading.

It also completes Chinese and English copy, mobile layouts, and cross-browser regression coverage.
