# v0.4.6

## 简体中文

本版本完成阅读与媒体资源架构升级，使用统一的卷资源模型承载电子书、漫画、PDF、纯文本和有声书内容。新的 Reader v3 接口与 Foliate 阅读运行时改善了 EPUB、MOBI、AZW3、FB2、TXT 等可重排格式的兼容性，并完善章节跳转、进度恢复、书签、主题与翻页交互。

书库详情与导入流程得到重构：作品可按卷管理章节和媒体文件，支持更清晰的卷排序、元数据编辑、目录选择与本地阅读进度展示。导入器增强了 PDF、音频和可重排电子书的元数据与封面提取，并修复纯数字卷号识别与遗留任务清理问题。

数据库升级加入分阶段、可恢复的媒体资源迁移和旧库结构规范化，提升现有书库升级的可靠性。Docker 构建补齐 Foliate 依赖，阅读器样式、移动端进度模型、后台授权与任务处理也获得一致性修正。

## English

This release completes a reader and media-resource architecture upgrade, using a unified volume resource model for ebooks, comics, PDFs, text, and audiobooks. The new Reader v3 API and Foliate-based runtime improve support for EPUB, MOBI, AZW3, FB2, TXT, and other reflowable formats, with stronger chapter navigation, progress restoration, bookmarks, themes, and paging interactions.

Library details and import workflows have been redesigned around volume-aware chapter and media management. Users gain clearer volume ordering, metadata editing, directory selection, and local reading-progress presentation. Importers now extract richer metadata and covers from PDFs, audio, and reflowable books, while numeric-only volume detection and invalid legacy-task cleanup are fixed.

Database upgrades now include staged, recoverable media-resource migrations and legacy schema normalization for more reliable upgrades of existing libraries. Docker builds include the Foliate dependency, and this release also aligns reader styling, mobile progress models, backend authorization, and background-task behavior.
