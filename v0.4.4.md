# v0.4.4

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本改进了有声书导入与作品归组：扫描和导入流程会更稳定地识别媒体类型、卷册与作品身份，减少同一本有声书被错误拆分或重复归档的情况，并补充了相关回归覆盖。

阅读器修正了 PDF 默认布局与翻页行为，使首次打开和设置恢复更符合当前阅读模式。整理记录列表改为直接读取所需的轻量字段，并集中加载元数据来源，减少不必要的完整详情组装和数据库查询。

系统事件与日志链路也经过优化，降低日志维护和高频事件记录对导入、书库及其他操作响应速度的影响。同时统一了 Shuku Starship 品牌标识、部署配置与运行时元数据，并清理了不再需要的审计产物。

## English

This release improves audiobook importing and work grouping. Scanning and import flows now identify media types, volumes, and work identities more consistently, reducing cases where one audiobook is split incorrectly or archived more than once, with expanded regression coverage for these paths.

The reader fixes PDF default layout and page-turn behavior so first-open and restored settings better match the active reading mode. The organize history now queries only the lightweight fields required by the list and loads metadata sources in batches, avoiding unnecessary detail assembly and database work.

System event and logging paths have also been optimized to reduce the impact of maintenance and high-frequency event recording on imports, library operations, and general responsiveness. Shuku Starship branding, deployment configuration, and runtime metadata are now aligned, and obsolete audit artifacts have been removed.
