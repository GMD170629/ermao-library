# v1.5.1

<!-- shuku:locale=zh-CN:start -->
## 新增：

1. 支持手动上传 ZIP 备份并加入备份列表；同名文件自动追加编号，保留已有备份。

## 修复：

1. 修复通过局域网 HTTP 地址访问时，删除图书资源失败的问题。
2. 备份列表显示当前版本兼容性及具体原因，不兼容或无法校验的备份不可恢复；创建备份时明确提示兼容性限制。
3. 恢复备份失败时展示具体原因和错误详情，便于识别文件损坏、版本不匹配、数据校验及写入错误。

<!-- shuku:locale=zh-CN:end -->

<!-- shuku:locale=en-US:start -->
## Added:

1. Added manual ZIP backup uploads to the backup list. Duplicate filenames receive numbered suffixes, preserving existing backups.

## Fixed:

1. Fixed book resource deletion failing when accessing the library over a local HTTP address.
2. Backup lists now show compatibility with the current version and specific reasons. Incompatible or unverifiable backups cannot be restored, and backup creation clearly explains compatibility limits.
3. Failed restores now show specific reasons and error details for damaged files, version mismatches, invalid data and write failures.
