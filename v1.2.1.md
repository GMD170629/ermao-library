# v1.2.1

<!-- shuku:locale=zh-CN:start -->
## 修复

- 修复手动识别图书时未先读取本地元数据的问题，优先利用书籍文件中已有的信息，再进行在线查找。
- 修复平铺书库导入时出版物标题被文件名覆盖的问题，保留书籍自身的标题信息。

## 升级说明

- 已使用 v1.2.0 基础环境的用户可通过应用内在线更新安装本次修复，无需更换容器镜像或 fnOS 安装包。
- 更早的基础环境请先升级到 v1.2.0。更新保留现有数据和登录状态，安装时服务会短暂重启。
<!-- shuku:locale=zh-CN:end -->

<!-- shuku:locale=en-US:start -->
## Fixes

- Fixed manual book identification skipping local metadata. Information embedded in book files is now read before an online lookup.
- Fixed flat-library imports replacing publication titles with filenames, preserving the titles supplied by the books themselves.

## Upgrading

- Users on the v1.2.0 base runtime can install these fixes through the in-app updater without replacing their container image or fnOS package.
- Older base runtimes must first upgrade to v1.2.0. Existing data and login sessions are retained; installation briefly restarts the service.
