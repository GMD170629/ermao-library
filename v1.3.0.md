# v1.3.0

<!-- shuku:locale=zh-CN:start -->
## 修复与改进

- 修复在线更新无法识别更新包下载信息而在安装预检阶段失败的问题，允许更新清单增加扩展字段。
- 简化在线更新校验：下载完成和安装前核对文件 SHA-256，不再因环境指纹、Python ABI、声明大小或本地依赖内容差异阻止安装。
- 保留管理员权限、安全解压、停机备份和失败保护；更新成功以服务实际启动并运行目标版本为准，安装日志记录具体阶段及错误码。

## 升级说明

- 本次更新包含固定安装器修复。现有用户请通过容器管理界面升级至 v1.3.0 完整镜像，或通过 fnOS 管理界面升级安装包，不能仅使用旧版本的应用内更新完成此次修复。
- 升级时保留原有数据目录及挂载配置，无需进入容器执行修复命令。完成本次升级后，后续应用更新将使用简化后的在线更新流程。

## Fixes and improvements

- Fixed installation preflight failures caused by unrecognized update download metadata. Update manifests now tolerate additional fields.
- Simplified online update verification: downloaded files are checked against their expected SHA-256 values after download and again before installation. Environment fingerprints, Python ABI, declared sizes and local dependency content differences no longer block installation.
- Administrator permissions, safe extraction, shutdown backups and failure protection remain in place. Success requires the service to start with the target version; installation logs record the failing stage and error code.

## Upgrading

- This release repairs the fixed installer. Existing users must upgrade to the complete v1.3.0 image through their container management interface, or upgrade the package through fnOS. The old in-app updater cannot deliver this installer repair on its own.
- Preserve the existing data directory and volume configuration. No repair commands inside the container are required. After this upgrade, subsequent application updates will use the simplified online update process.
