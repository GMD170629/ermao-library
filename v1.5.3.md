# v1.5.3

<!-- shuku:locale=zh-CN:start -->
## 修复：

1. 缩短图书导入、批量操作和元数据更新占用数据库写锁的时间，减少少量图书更新时的卡顿。
2. 系统日志容量改按数据库实际占用统计；达到上限后从最旧记录开始清除一半，避免反复计算日志内容导致查询超时。
3. 数据库锁等待最长延至 30 秒，超时和长事务日志记录执行阶段与耗时，方便直接定位卡顿原因。
4. 修复反馈提交时诊断事件时间格式与预览不一致的问题。

<!-- shuku:locale=zh-CN:end -->

<!-- shuku:locale=en-US:start -->
## Fixed:

1. Shortened database write lock duration during book imports, bulk actions, and metadata updates to reduce stalls on small updates.
2. System log capacity now uses actual database storage. At the limit, cleanup removes the oldest half of the rows without repeatedly measuring log content.
3. Database lock waits now allow up to 30 seconds, while timeout and long transaction logs include execution stages and timings for diagnosis.
4. Fixed a timestamp mismatch between feedback preview and submitted diagnostic events.
