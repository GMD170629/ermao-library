# v0.4.3

<!-- shuku:locale=zh-CN:start -->
## 简体中文

关于页面现已内置正式版本更新检查与完整更新历史。当公开发布通道出现更高稳定版本时，系统会在设置导航和关于页面给出提示，并按当前语言展示对应的版本说明。

更新历史由仓库中的双语 Markdown 统一维护，并在 GitHub Release 成功发布后同步到独立的公开 `release-feed`。未发布版本不会提前出现在应用中，远程数据异常时也会显示明确的失败状态并支持重试。

发布流程现已强制校验根包、Web、Python 后端、运行时配置、锁文件与标签的版本一致性。每个正式版本必须提供经过人工校对且内容完整的中文和英文说明；缺失语言、占位内容、正文不一致或构建失败都会阻止 Release、镜像和 fnOS 包正式发布。

## English

The About page now includes stable-version update checks and a complete release history. When a newer stable version appears in the public channel, the application shows an indicator in Settings and presents the localized release notes on the About page.

Release history is maintained from authoritative bilingual Markdown in the repository and copied to a dedicated public `release-feed` only after the matching GitHub Release is successfully published. Unreleased versions remain hidden, while invalid or unavailable remote data produces a clear retryable error state.

The release pipeline now enforces version consistency across the root package, Web app, Python backend, runtime configuration, lockfile, and Git tag. Every formal release requires substantive, human-reviewed Chinese and English notes; missing locales, placeholders, body mismatches, or failed builds block publication of the Release, container images, and fnOS package.
