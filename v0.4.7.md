# v0.4.7

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本提升多卷作品的导入与整理能力。导入器现在能更稳定地识别卷号、排序卷册并将相关文件归入同一作品，兼顾电子书、漫画、PDF、纯文本和有声书；书库智能筛选与作品详情查询也同步完善，详情页会展示每卷关联的源文件路径，便于核对整理结果。

EPUB 阅读器修复了固定版式书籍缺失或无效视口尺寸时页面缩小的问题，并增强 Foliate 适配层对固定版式元数据的规范化与测试覆盖。导入身份解析、作品分组、卷排序和后台任务均新增回归测试，以提升重复导入和复杂命名场景下的可靠性。

## English

This release improves importing and organizing multi-volume works. Importers now identify volume numbers, order volumes, and group related files into the same work more reliably across ebooks, comics, PDFs, text, and audiobooks. Library smart filters and work-detail queries are aligned with the new grouping behavior, while the detail page now shows each volume's source file paths for easier verification.

The EPUB reader fixes undersized pages in fixed-layout books with missing or invalid viewport dimensions. The Foliate adapter now normalizes fixed-layout metadata and includes stronger regression coverage. Additional tests cover import identity resolution, work grouping, volume ordering, repeated imports, and background import tasks.
