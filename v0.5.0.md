# v0.5.0

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本新增 OPDS 书库访问能力，并完善书库整理工作流。现在可以通过 OPDS 浏览作品、卷册和文件，Web 端请求会稳定转发到后端；作品详情新增卷册上下文管理，导入流程也增强了对有声书、CBR、RAR 漫画归档及媒体类型的识别和归类。

元数据识别与文件回写现已统一，并为自动查询加入按提供商配置的限流保护，降低批量整理时触发外部服务限制的风险。Foliate 阅读缓存、阅读入口恢复以及导入分组和卷序判断也得到改进，并补充了相关中英文界面与回归测试。

## English

This release adds OPDS library access and expands organization workflows. Readers can browse works, volumes, and files through OPDS with reliable Web-to-backend routing. Work details now include volume context management, while imports recognize and classify more audiobook formats, CBR and RAR comic archives, and media types.

Metadata resolution and file writeback now use a unified workflow, with provider-specific automatic rate limiting to reduce external-service throttling during bulk organization. Foliate caching, reading-entry recovery, import grouping, and volume ordering are also improved, with matching bilingual UI updates and regression coverage.
