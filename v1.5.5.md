# v1.5.5

<!-- shuku:locale=zh-CN:start -->
## 修复：

1. 书库已有扫描或导入任务时，启动检查和定时扫描会跳过本次触发，避免重复任务堆积。
2. 网页书库设置中的定时扫描简化为开启／关闭，开启后固定每 24 小时执行一次，不再提供自定义频率；原有关闭设置保持有效。
3. 页面预览缓存生成满 7 天后失效，后台每天清理过期预览，再次访问时自动重新生成，减少长期积存。

## 注意事项：

1. 升级会清除尚未完成的整库扫描任务，包括手动发起的任务。仍需扫描的书库请重新发起扫描；其他导入任务和已有图书保留。

<!-- shuku:locale=en-US:start -->
## Fixed:

1. Startup checks and scheduled scans now skip libraries that already have scan or import tasks, preventing duplicate tasks from piling up.
2. Scheduled scanning in the web library settings is now a simple on/off switch. When enabled, scans run every 24 hours without a custom frequency; previously disabled settings remain disabled.
3. Page preview caches expire seven days after generation. Daily cleanup removes expired previews, which are regenerated automatically when next opened, reducing long-term accumulation.

## Notes:

1. The update removes unfinished whole-library scan tasks, including manually started scans. Start another scan for any library that still needs one; other import tasks and existing books are retained.
