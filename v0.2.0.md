## 简体中文

本版本建立统一的生产部署和应用打包基础，使 Web、后端服务与自托管运行环境能够作为一个完整产品交付。

同时完善容器启动、持久化存储和正式版本资产，为后续 fnOS 与 Docker 发布流程提供稳定基础。

## English

This release establishes a unified production deployment and packaging foundation so the Web app, backend service, and self-hosted runtime can ship as one product.

It also improves container startup, persistent storage, and versioned release assets, providing a stable base for subsequent fnOS and Docker delivery.
