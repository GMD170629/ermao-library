# v0.3.0

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本加入完整的简体中文与英文国际化支持，界面、消息与 PWA 元数据可随语言切换。

新增多用户、角色和书库目录级权限管理，并支持会话撤销与用户数据隔离。设置中心新增按用户与设备保存的 EPUB、漫画、PDF 和音频偏好，同时优化 PWA、阅读器与移动端体验。

监控文件夹不再绑定全局书架，每位用户可按来源文件夹创建自己的智能书架。

## English

This release introduces complete Simplified Chinese and English localization, including interface copy, messages, and PWA metadata that follow the active language.

It adds multi-user support, roles, library-directory permissions, session revocation, and user-data isolation. Settings can now preserve EPUB, comic, PDF, and audio preferences per user and device, alongside PWA, reader, and mobile improvements.

Monitor folders are no longer tied to a global shelf, allowing each user to create smart shelves from source folders.
