单一收敛假设：把相同角色的容器、内部留白与操作工具统一到共享 owner，在不扩大主体内容占屏的情况下消除导航接缝、控件混用和宽菜单。

保留首页/书库/书架/我的分区、三列网格、目录96dp封面、资源120dp封面与无空元数据的 v1 改善。新增交互仅为目录路径展开及现有路径选择。保留全部业务回调，不发送邮件、提交真实配置、修改账户或下载/删除文件。未要求 Reader、后端、iOS、对比度、大字体、TalkBack 或横屏专项。

目标蓝图：底栏 `［4dp外侧 | 胶囊［6dp上下内边距 + 图标/文案］| 4dp外侧］→同色系统手势区`；目录工具栏 `［当前目录 ⌄（展开完整路径）］［网格/列表图标］［排序图标］`；设置过滤 `全部━━━━ 进行中 失败`；操作 Popup `≤224dp宽 / 16dp圆角 / 12dp左右 / ≥48dp行 / 24dp图标`。这些尺寸来自用户明确目标、已有契约与现有浮动菜单宽度，不另建跨平台数值契约。
