# v0.2.3

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本集中修复打包与发布流程，使 fnOS 安装包、Docker 镜像和应用版本能够在同一次正式发布中保持一致。

同时整理生产构建产物和发布资产命名，减少重复发布时的人工操作，并补充关键打包路径的校验。

## English

This release focuses on packaging and delivery reliability so the fnOS package, Docker image, and application version stay aligned within one formal release.

It also cleans up production artifacts and release-asset naming, reduces manual work during repeat publishing, and adds validation around the critical packaging paths.
