# 反馈与报错 Web 交互原型

基于二毛图书 v1.5.1 的「关于」和「系统日志」真实页面布局、色彩及现有表单和按钮样式制作。仅用于讨论交互，日志、图书、反馈编号均为演示数据；提交不会访问官网或发送邮件。

在仓库根目录运行 `node prototypes/feedback-web/server.mjs`，打开 `http://127.0.0.1:4173/prototypes/feedback-web/`。

可体验：关于页入口、功能建议、手动报错、从日志详情发起、关联日志与图书预览、联系方式、表单校验、提交核对、成功与失败重试、管理员与普通用户可见范围、窄屏布局。

表单采用单个 Markdown 正文字段。功能建议显示「详细说明」，报错显示「问题描述」，打开时分别放入可修改的填写提纲。可选择图片或附件、拖放文件、预览 Markdown、移除文件；演示限制为最多 5 个文件、单个不超过 10 MB、合计不超过 15 MB。文件只在当前浏览器内用于原型交互，不会上传到任何服务器。

系统环境默认不发送。勾选后可以预览演示数据，包含应用版本、安装方式、客户端形态、浏览器与系统、语言、时区、窗口尺寸、当前页面。正式实现应由服务端提供可信的应用版本和安装方式，并在确认提交后收集；界面明确排除账号、令牌、IP、书库路径和图书列表。日志仍须单独勾选。

设计中的文件生命周期：浏览器保留本地文件直到提交成功或用户关闭草稿；官网服务器仅在本次邮件处理期间临时持有文件，邮件发送成功或失败均立即清理。发送失败时浏览器保留草稿和本地文件用于重试。邮件成功送达后，其附件仍保留在收件邮箱；原型只模拟这些状态，不执行真实传输或清理服务器文件。
