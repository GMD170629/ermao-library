## 可见一致性检查

- 保留当前项目的暖白背景、珊瑚色主操作、细边框、低阴影和圆角卡片。
- 复用项目内真实应用图标和真实备用封面素材，没有使用占位图、ASCII、手绘 SVG 或 CSS 图形冒充资产。
- 移动端继续使用双列封面、固定底部导航和全宽弹层；桌面端延展为左侧导航与内容工作区。
- 信息密度与当前项目接近；新增管理能力放入“书库整理”和按需弹层，没有把管理控件持续堆在阅读入口上。
- 移动端页面没有横向溢出；需要横向滚动的分类标签栏隐藏了系统滚动条，同时保留触控滚动。

## 交互验收

- 筛选：打开“更多筛选” → 选择“进行中” → 数量由 8 更新为 3 → 应用后显示 3 本。
- 智能书架：把当前筛选保存为“正在阅读” → 侧边栏出现书架与 3 本计数。
- 批量标签：进入选择模式 → 选择《三体》《流浪地球》 → 添加“待读” → 预览 2 本变化 → 确认成功。
- 重复治理：检查《三体》候选 → 比较两条作品 → 预览合并 → 确认后两个文件版本均保留，并显示可撤销反馈。
- 分类治理：选择“刘慈欣 / 劉慈欣” → 合并作者 → 规范项保留为“刘慈欣”，旧名称不再作为独立项出现。
- 元数据模型：图书详情 → 编辑信息 → 在“作品信息 / 版本信息”之间切换；版本页包含出版社、出版日期、语言、ISBN、格式与来源。
- 内容拆分：管理内容结构 → 拆分 PDF 后备版本 → 预览源作品与新作品 → 确认完成，文件位置保持不变。
- 浏览器控制台：0 条 error / warn。
- 构建验证：`npm run build` 通过；`npm run test:sites` 4/4 通过。
