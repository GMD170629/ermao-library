# v1.5.4

<!-- shuku:locale=zh-CN:start -->
## 新增：

1. 系统日志支持清空全部记录，操作前需确认，清空后同步刷新列表和详情。

## 修复：

1. 修复图书使用书库相对路径时 OPF 元数据写回失败的问题。
2. 清空日志时一并删除错误和审计记录，清空操作不再额外留下日志。
3. 慢数据库写事务日志仅记录超过 1 秒的事务，减少短事务产生的诊断噪声。

<!-- shuku:locale=zh-CN:end -->

<!-- shuku:locale=en-US:start -->
## Added:

1. System logs can now clear all records after confirmation, refreshing both the list and details.

## Fixed:

1. Fixed OPF metadata writeback failures for books using library-relative paths.
2. Clearing logs now removes error and audit records without adding another log entry for the clear operation.
3. Slow database write transaction logs now report only transactions longer than one second, reducing diagnostic noise from short transactions.
