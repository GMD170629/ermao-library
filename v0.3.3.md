# v0.3.3

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本重点提升漫画阅读、听书元数据兼容性与书架信息展示。

- 漫画省流模式改用自适应 AVIF 压缩，完善缓存与降级处理。
- 自动修复常见旧音频标签编码错误，同时保留正常的中英文及西文元数据。
- 书架新增书名与作者信息带，并改善宽屏和多行书架布局。
- 支持更大的本地有声书导入，并完善生产镜像发布流程。
<!-- shuku:locale=zh-CN:end -->

## English

This release focuses on comic reading efficiency, audiobook metadata compatibility, and clearer shelf information.

- Comic data-saving mode now uses adaptive AVIF compression with stronger caching and fallback behavior.
- Common legacy audio-tag encoding errors are repaired while valid Chinese, English, and Western metadata remains unchanged.
- Shelves now show title and author information with improved wide-screen and multi-row layouts.
- Larger local audiobook imports are supported and the production image publishing flow is more reliable.
