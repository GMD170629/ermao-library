# v0.5.2

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本修复书库智能筛选中的监控文件夹过滤。筛选现在根据监控文件夹的真实路径匹配可见卷册文件，只要图书的任一卷册位于所选文件夹内，就会返回该图书；路径边界也会被正确识别，避免名称前缀相似的相邻目录被误匹配。

筛选项已将“原始文件夹”更名为“监控文件夹”，并把“原始文件路径”移动到其下方。后台会批量解析筛选涉及的目录，并使用数据库相关子查询完成匹配，以兼顾大规模书库下的查询性能和文件夹访问权限。

<!-- shuku:locale=en-US:start -->
## English

This release fixes monitor-folder filtering in the library's smart filters. Filters now match the real file paths of visible volumes, returning a book when any volume is inside the selected folder while preserving directory boundaries so similarly prefixed sibling folders are not included.

The filter label is renamed from “Original folder” to “Monitor folder,” and “Original file path” now appears directly below it. The backend resolves selected folders in batches and uses correlated database queries to preserve folder authorization and query performance for large libraries.
