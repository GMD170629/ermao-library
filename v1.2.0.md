# v1.2.0

<!-- shuku:locale=zh-CN:start -->
## 新增与改进

- 支持手动调整书库根目录的全局顺序，按自己的习惯组织内容。
- 更新默认封面；识别图书时可预览候选封面，应用识别结果后自动关闭识别面板。
- 改进后台异常记录与展示，便于定位扫描、导入和元数据处理失败的原因，并加强日志中的敏感信息保护。

## 修复

- 修复扫描缺口恢复、局部扫描范围和任务等待问题，避免无关目录的失败影响其他导入任务。
- 改善启动与后台任务故障隔离，减少元数据恢复、维护任务或 Worker 异常对登录、浏览和阅读的影响。
- 修复更换容器镜像后程序版本未同步的问题；同一镜像普通重启继续保留在线更新后的版本。
- 修复更新过程中将 Worker 启动失败误判为核心服务超时的问题。

## 升级说明

- 从 v1.1.0 升级请更新 Docker 镜像或 fnOS 应用。本版本包含基础运行环境与容器启动器变更，不支持从 v1.1.0 直接在线升级。
- 保留原有数据目录与图书目录挂载，升级前备份数据库和配置。升级包含数据库迁移，请勿直接切回旧镜像尝试降级。

## Features and improvements

- Manually reorder library roots globally to organize content in your preferred order.
- Refreshed the default cover. Book identification now previews candidate covers and closes the identification panel after applying a result.
- Improved backend error recording and display to help diagnose scanning, import, and metadata failures, with stronger protection for sensitive information in logs.

## Fixes

- Fixed scan-gap recovery, scoped scanning, and task waiting so failures in unrelated directories do not block other import tasks.
- Improved startup and background-task isolation to reduce the impact of metadata recovery, maintenance, and Worker failures on login, browsing, and reading.
- Fixed application synchronization when replacing a container image. Ordinary restarts with the same image continue to retain the version installed through an in-app update.
- Fixed updates incorrectly reporting a Worker startup failure as a core-service timeout.

## Upgrading

- To upgrade from v1.1.0, update the Docker image or fnOS application. This release changes the base runtime and container launcher and does not support a direct in-app upgrade from v1.1.0.
- Keep existing data and book-directory mounts, and back up the database and configuration before upgrading. This release includes database migrations; do not attempt a downgrade by switching directly to an older image.
