# v1.4.0

<!-- shuku:locale=zh-CN:start -->
## 自动化接入与书库管理

- 新增 MCP 自动化接入与授权管理，可按授权范围查询书库、管理书架和标签、读取或更新元数据，并执行原文件操作。设置页提供授权、动态接入和操作记录，便于管理自动化客户端。
- 支持选择性刷新与写回元数据，保留手动保护的字段；封面引用和文件版本检查减少误写与过期操作。
- Web 书籍详情支持按卷册选择并下载原文件，便于保存需要的内容。

## 文件操作与恢复

- 改善文件移动、重命名及跨磁盘复制的恢复处理，保留关联文件和书库身份；移动卷册后重新导入，保持完整书籍的归属正确。
- 修复局部扫描对普通文件的更新处理，并同步书库排序。
- 改进文件删除及未完成操作提示；失败信息提供可追踪的原因，便于定位导入、后台处理和自动化操作问题。
- 加强在线更新失败恢复与运行状态反馈，改善启动和更新异常的诊断。

## Automation and library management

- Added MCP automation access and grant management. Authorized clients can query the library, manage shelves and tags, read or update metadata, and perform source-file operations. Settings now provide grants, dynamic access, and operation history.
- Added selective metadata refresh and writeback while preserving manually protected fields. Cover references and file-version checks help prevent unintended writes and stale operations.
- Book details on the web now let you select volumes and download their original files.

## File operations and recovery

- Improved recovery for moves, renames, and cross-device copies while preserving companion files and library identities. Moved volumes are reimported with correct ownership for complete books.
- Fixed regular-file reconciliation during scoped scans and synchronized library ordering.
- Clarified file deletion and incomplete-operation feedback. Traceable failure details help diagnose import, background processing, and automation errors.
- Strengthened online-update recovery and runtime status reporting, with improved startup and update failure diagnostics.
