# v1.4.3

<!-- shuku:locale=zh-CN:start -->
## 新增：

1. 在图书详情中点击作者姓名，可按该作者筛选书库。

## 修复：

1. 修复部分 EPUB 因可选字体引用越出出版物目录而无法打开的问题；阅读时仍会阻止不安全的外部访问。
2. 优化首页“继续阅读”的查询，正确显示最近阅读且仍可见的未读完图书。
3. 修复健康检查对已配置书库目录及导入任务处理状态的判断。

<!-- shuku:locale=zh-CN:end -->

<!-- shuku:locale=en-US:start -->
## Added:

1. Click an author's name on a book's detail page to filter the library by that author.

## Fixed:

1. Fixed EPUB books failing to open because optional font references escape the publication directory; unsafe external access remains blocked.
2. Improved the home page's Continue Reading query to show the most recently read, visible, unfinished book.
3. Fixed health checks for configured library directories and import worker status.
