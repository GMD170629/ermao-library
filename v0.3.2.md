# v0.3.2

<!-- shuku:locale=zh-CN:start -->
## 简体中文

本版本完成多卷有声书支持，覆盖目录发现、导入、卷册切换、播放和进度跟踪；迷你播放器与作品详情也可选择卷册。

导入可靠性进一步提升：源文件丢失和工作进程中断会进入清晰、可恢复的终态，中断的后台任务可以安全重新排队，监控目录也允许明确设置最小文件大小为零。

Web、后端运行时、Python 包元数据和锁文件版本已统一，并通过后端与 Web 测试、类型检查、生产构建和国际化验证。

## English

This release completes multi-volume audiobook support across directory discovery, import, volume switching, playback, and progress tracking. The mini player and work details now provide volume selection for multi-volume editions.

Import reliability is also improved: missing source files and interrupted workers now reach clear, recoverable terminal states, while interrupted background tasks can be safely re-queued. Monitor folders can now explicitly use a minimum file size of zero.

The Web app, backend runtime, Python package metadata, and lockfile are synchronized, with backend and Web tests, type checking, the production build, and internationalization validation completed.
