# v1.5.6

<!-- shuku:locale=zh-CN:start -->
## 新增：

1. 系统日志改为按天保存文件，默认保留最近 3 天（包含今天），支持设置保留天数和 debug、info、warning、error 最低记录级别，默认仅记录 error。

## 修复：

1. 统一异常记录，保留完整错误原文、堆栈和原因链；简化日志设置与展示，移除关联信息和日期搜索，支持关键字筛选、复制、原始日志文件导出及单条日志反馈。
2. 修复缺少系列序号或可选 OPF 元数据时产生错误日志的问题，正常缺省信息不再被误报为错误。
3. 统一设置的保存格式，修复旧设置反复产生解析错误的问题，并保留已有设置值。
4. 修复网页阅读器触摸翻页与动态视口高度适配问题。

<!-- shuku:locale=zh-CN:end -->

<!-- shuku:locale=en-US:start -->
## Added:

1. System logs are now saved in daily files and retained for three days by default, including today. Retention days and the minimum logging level can be configured as debug, info, warning, or error; the default is error.

## Fixed:

1. Unified exception recording preserves complete error messages, stack traces, and cause chains. Simplified log settings and display remove correlation details and date searches while retaining keyword filtering, copying, original log file exports, and feedback for individual entries.
2. Missing series numbers or optional OPF metadata no longer produce false error logs.
3. Standardized saved settings to fix repeated parsing errors from older settings while preserving their existing values.
4. Fixed touch page turning and dynamic viewport height handling in the web reader.
