# v1.3.1

<!-- shuku:locale=zh-CN:start -->
## 修复与改进

- 新增书籍“加入书架”操作，可以在操作菜单中选择目标书架，将书籍加入已有书架。
- 修复书架选择弹窗中的下拉菜单被遮挡或无法操作的问题，并改善键盘关闭菜单与返回焦点的体验。
- 修复在线更新失败后，遗留的更新请求或失败标记阻止容器正常重启的问题；重启后保留失败信息，便于查看原因并重新准备更新。
- 改善更新准备阶段的失败处理和状态提示，明确区分下载准备、安装与失败状态。

## 升级说明

- 本次包含容器启动入口修复。请通过容器管理界面升级至 v1.3.1 完整镜像，或通过 fnOS 管理界面升级安装包，以获得更新失败后的重启修复。
- 升级时保留现有数据目录和挂载配置；无需进入容器执行修复命令。仅安装应用内更新包不会替换旧镜像中的固定启动入口。

## Fixes and improvements

- Added an Add to shelf action to the book menu so books can be placed on an existing shelf.
- Fixed shelf selector menus being hidden or unusable inside the dialog, and improved keyboard dismissal and focus restoration.
- Fixed stale update requests or failure markers preventing containers from restarting after a failed online update. Failure details remain available after restart so administrators can inspect the cause and prepare another update.
- Improved failure handling and status messages during update preparation, distinguishing downloaded packages, installation and failures.

## Upgrading

- This release repairs the fixed container startup entry point. Upgrade to the complete v1.3.1 image through your container management interface, or upgrade the package through fnOS, to receive the restart fix.
- Preserve your existing data directory and volume configuration. No repair commands inside the container are required. Installing only the in-app update package does not replace the fixed startup entry point in an older image.
