# v1.4.1

<!-- shuku:locale=zh-CN:start -->
## 修复

- PDF 导入和文件元数据读取现在会合并 Info 与 XMP 标准字段，优先使用有效的 XMP 值；XMP 缺损时保留 Info 中可读取的信息。写回前的元数据预览也显示同一结果。
- PDF 主题词中的正斜杠、反斜杠和中划线现在可拆分为独立标签。已有 PDF 会在重新扫描时更新标签；例如“儿童文学/奇幻/冒险”会显示为三个标签。

## 升级说明

- 已使用 v1.4.0 基础环境的用户可通过应用内在线更新安装本次修复。更早的基础环境请先升级到 v1.4.0；安装更新时服务会短暂重启。
<!-- shuku:locale=zh-CN:end -->

<!-- shuku:locale=en-US:start -->
## Fixes

- PDF imports and file metadata reads now merge standard Info and XMP fields, preferring valid XMP values while retaining readable Info values when XMP is damaged. The pre-write metadata preview uses the same result.
- Forward slashes, backslashes, and hyphens in PDF subjects now separate individual tags. Existing PDFs update their tags on the next scan; for example, “Children's literature/Fantasy/Adventure” becomes three tags.

## Upgrading

- Users on the v1.4.0 base runtime can install this fix through the in-app updater. Older base runtimes must first upgrade to v1.4.0; installation briefly restarts the service.
